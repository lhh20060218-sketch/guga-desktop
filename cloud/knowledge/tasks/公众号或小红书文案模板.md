# 任务模板：公众号或小红书文案

## 目标示例
少爷：这周发一篇小红书，主题"老板桌上升职加薪 5 件套"，要爆，发之前给我看一版。

## 子任务拆解

### 1. 选题与对标调研
- **执行方类型**：秘塔AI搜索 + Perplexity
- **一句话验收标准**：拉出近 30 天同主题爆款笔记 5 篇，列出共同标题套路（数字型 / 反差型 / 人群标签型）和封面特征，每条附原帖链接。

### 2. 正文撰写
- **执行方类型**：豆包
- **一句话验收标准**：出一篇 800–1000 字笔记，emoji 分段、3 个可立即照做的建议、结尾抛一个互动提问，无"家人们谁懂啊"这类过度网感词。

### 3. 标题变体
- **执行方类型**：豆包
- **一句话验收标准**：给 5 个候选标题（带数字 / 带反差 / 带人群标签各至少 1 个），每个标题 ≤ 20 字，少爷从中选 1 个。

### 4. 封面图
- **执行方类型**：即梦（生图）+ Canva（加字排版）
- **一句话验收标准**：1 张 3:4 封面，大字标题 ≤ 12 字、主体产品清晰、背景干净无杂物，少爷审过定稿。

## 预计顺序
1. **选题与对标调研**（串行前置）——不看爆款写出来就是自嗨。
2. **正文撰写**（依赖 1，串行）——按对标套路写。
3. **标题变体**（依赖 2，建议串行）——正文定稿后再拟标题更贴合内容，但也可与 2 后半段并行。
4. **封面图**（与 2、3 可并行）——封面不依赖正文细节，只依赖标题和主体。
