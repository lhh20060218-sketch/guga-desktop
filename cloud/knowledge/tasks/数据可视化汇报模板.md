# 任务模板：数据可视化汇报

## 目标示例

少爷：这季度的销售数据，你给我做成一张能上会的可视化汇报，周四前。

## 子任务拆解

1. **盘数据与口径**
   - 执行方类型：少爷（给 Excel / CSV 原始数据）+ 咕嘎（核对字段、口径、时间范围）
   - 验收标准：先问清楚"按什么时间粒度看（月/周）、按什么维度切（区域/产品线）、关注什么指标（GMV/客单价/转化）"；口径不一致的当场跟少爷对齐，不带歧义往下做。

2. **算核心指标**
   - 执行方类型：WPS Office（表格公式 / 数据透视）或 Cursor（如需写 Python 跑数），咕嘎（抽查 3 个数手算核对）
   - 验收标准：核心指标算完写在一页上，每个数字标注口径和时间范围；咕嘎至少抽查 3 个数，手算结果与表格一致才算过，不一致先查公式不直接抄。

3. **挑图表类型**
   - 执行方类型：豆包 / ChatGPT（基于"想看什么结论"推荐图表：趋势用折线、对比用柱状、占比用饼图或堆叠、漏斗用漏斗图）
   - 验收标准：每个图表对应一个想讲的结论，不允许"为了好看而画"；图表数控制在 5–8 张，上会看不完的砍。

4. **出汇报稿**
   - 执行方类型：Gamma（生成演示文稿）或 Canva（做关键页），咕嘎（导出 PPT / PDF）
   - 验收标准：每页一个结论 + 一张图 + 一句解读；开场 30 秒说清"本季度最重要的一件事"；少爷过目定稿。

## 预计顺序

1. 盘数据与口径 —— 第一步，口径不清后面全错。
2. 算核心指标 —— 串行，口径定了才算数。
3. 挑图表类型 —— 串行，指标定了才知道画什么。
4. 出汇报稿 —— 最后一步，图表和文字稿少爷点头后再排版。
