# 任务模板：文件整理归档

## 目标示例
少爷：把桌面和下载目录这一堆乱文件按项目归档一下，年底了我要找东西快一点，别删我东西。

## 子任务拆解

### 1. 扫描盘点
- **执行方类型**：咕嘎（调度/汇总）+ 豆包
- **一句话验收标准**：输出桌面与下载目录完整文件清单（含文件名、大小、修改时间、扩展名），文件总数与目录实际文件数一致，不遗漏隐藏文件。

### 2. 分类方案设计
- **执行方类型**：DeepSeek（深度推理）
- **一句话验收标准**：给出"项目 / 年份 / 文件类型"三级目录树草案，每一类附上 3 个示例文件的归属说明，少爷一眼能判断分类逻辑对不对。

### 3. 执行搬运与重命名
- **执行方类型**：咕嘎（执行）+ WPS Office（表格登记）
- **一句话验收标准**：按方案搬运完成，所有文件统一加日期前缀 `YYYYMMDD_`，归档后目录内无重复文件名、无空文件夹、无遗漏在原位置的散文件。

### 4. 索引清单交付
- **执行方类型**：Notion AI
- **一句话验收标准**：输出一份 Markdown 索引表，含路径、命名规则、归档日期三列，少爷打开 Notion 输入一个项目名能在 10 秒内定位到对应文件夹。

## 预计顺序
1. **扫描盘点**（串行前置）——没有清单就没法分类，必须先跑。
2. **分类方案设计**（依赖 1，串行）——方案要等清单出来才能定稿。
3. **执行搬运与重命名**（依赖 2 少爷审批后，串行）——搬运不可逆，必须等方案拍板。
4. **索引清单交付**（依赖 3 完成后，串行收尾）——索引要反映最终目录，不能提前写。
