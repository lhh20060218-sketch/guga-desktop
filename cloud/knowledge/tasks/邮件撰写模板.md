# 任务模板：邮件撰写

## 目标示例
少爷：给张总写封邮件，约下周三下午聊 Q4 预算，语气别太硬，他是我老领导但最近有点忙。

## 子任务拆解

### 1. 对象与目的确认
- **执行方类型**：咕嘎（整理）+ 少爷（确认）
- **一句话验收标准**：输出三行信息——收件人身份、期望对方动作（回复具体时段/回复"收到"）、抄送与密送范围，少爷一句话确认"就这样"。

### 2. 草稿撰写
- **执行方类型**：豆包（对话写作）
- **一句话验收标准**：一封 200–300 字邮件，含主题行、开场白、3 个可选时段（精确到小时）、明确的下一步动作（"您回复其中一个时段即可"）。

### 3. 语气校订
- **执行方类型**：Claude
- **一句话验收标准**：输出校订后版本，并用批注列出 3 处改动点（去 AI 腔、去掉过度客套、口语化但不失礼），全文不超过 350 字。

### 4. 附件与发送前检查
- **执行方类型**：咕嘎
- **一句话验收标准**：附件命名为 `YYYYMMDD_主题.pdf`，正文里提到的每一个附件名都能在附件栏找到对应文件，签名档和发件人地址正确。

## 预计顺序
1. **对象与目的确认**（串行前置）——对象错了草稿白写。
2. **草稿撰写**（依赖 1，串行）——按确认后的对象写。
3. **语气校订**（依赖 2，串行）——校订对象是草稿本身。
4. **附件与发送前检查**（依赖 3 定稿后，串行收尾）——定稿后才挂附件。
