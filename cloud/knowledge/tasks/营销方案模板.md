# 任务模板：营销方案

## 目标示例

少爷：下季度要推这款新品，给我一份能上会的营销方案，下周三前给我。

## 子任务拆解

1. **盘背景与目标**
   - 执行方类型：少爷（说清产品定位、目标人群、预算区间、上会对象是谁）+ 咕嘎（把少爷的口述整理成一页 brief）
   - 验收标准：brief 里写清楚"卖什么 / 卖给谁 / 花多少钱 / 想换回来什么指标"四件事，缺一项当场问少爷，不带着模糊目标往下写。

2. **竞品与渠道扫描**
   - 执行方类型：秘塔AI搜索 + Perplexity（联网查近 90 天竞品营销动作、行业投放渠道、可对标的爆款案例）
   - 验收标准：列出 3 个竞品近 90 天的主要动作 + 2 个可参考的爆款案例，每条附来源链接；查不到的写"未公开"，不许编数据。

3. **搭方案骨架**
   - 执行方类型：豆包 / 通义千问（基于 brief 和扫描结果，生成方案初稿）
   - 验收标准：初稿含四块——核心策略（一句话说清怎么打）、目标人群与卖点、渠道与节奏（时间线）、预算拆分；每块不少于 300 字，不允许只写标题不写内容。

4. **视觉化与上会版**
   - 执行方类型：Gamma（把方案转成演示文稿）或 Canva（做关键页排版），咕嘎（导出 PDF / PPT）
   - 验收标准：上会版 ≤ 15 页，每页一个核心观点；预算数字、时间节点在 PPT 里能一眼找到；少爷过目后定稿，不再临时加页。

## 预计顺序

1. 盘背景与目标 —— 第一步，brief 不冻结后面全返工。
2. 竞品与渠道扫描 —— 与 1 可部分并行，但扫描方向要等 brief 里"目标人群"定了才聚焦。
3. 搭方案骨架 —— 串行，等扫描结果回来才能写。
4. 视觉化与上会版 —— 最后一步，文字稿少爷点头后再做 PPT。
