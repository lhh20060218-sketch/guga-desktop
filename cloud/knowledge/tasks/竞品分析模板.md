# 任务模板：竞品分析

## 目标示例
少爷：我们要做一款 AI 笔记产品，帮我分析下 Notion AI、飞书妙计、Obsidian 插件这三家，下周评审会要用。

## 子任务拆解

### 1. 选竞品定维度
- **执行方类型**：咕嘎 + 少爷
- **一句话验收标准**：输出分析维度表（定价 / 核心功能 / 目标用户 / 优势 / 软肋 / 最近 90 天动态），少爷确认维度不增不减。

### 2. 分头调研
- **执行方类型**：秘塔AI搜索 + Perplexity
- **一句话验收标准**：每家出一份 800 字调研纪要，含官网定价页链接、最近 90 天更新日志、至少 1 条用户真实差评来源（App Store / 知乎 / V2EX）。

### 3. 对比矩阵表
- **执行方类型**：WPS Office 或 Notion AI
- **一句话验收标准**：输出一张三列对比矩阵，每个单元格 ≤ 20 字，关键差异（如某家免费额度、某家缺离线模式）用红色标注。

### 4. 结论与切入建议
- **执行方类型**：DeepSeek
- **一句话验收标准**：输出 500 字结论——我们切入哪个细分空白、避开哪场正面战、第一版 MVP 只做哪 3 个功能，少爷终审。

## 预计顺序
1. **选竞品定维度**（串行前置）——维度不定，调研无的放矢。
2. **分头调研**（三家可并行）——秘塔和 Perplexity 各跑一家，互不阻塞。
3. **对比矩阵表**（依赖 2 全部完成，串行）——三家调研都齐了才能填矩阵。
4. **结论与切入建议**（依赖 3，串行）——矩阵是结论的输入。
