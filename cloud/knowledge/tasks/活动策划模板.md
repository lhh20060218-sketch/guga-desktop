# 任务模板：活动策划

## 目标示例
少爷：下个月 15 号客户答谢会，200 人，预算 8 万，你给我出个策划案，月底前要过会。

## 子任务拆解

### 1. 目标与预算拆解
- **执行方类型**：DeepSeek（深度推理）
- **一句话验收标准**：输出一页纸——量化目标（到场率 ≥ 90%、现场签约意向 ≥ 20 家）和预算分配表（场地 / 餐饮 / 物料 / 礼品 / 应急各占百分比，合计 100%）。

### 2. 分工与排期表
- **执行方类型**：Notion AI
- **一句话验收标准**：输出倒排甘特表，标注 T-30 / T-15 / T-7 / T-1 四个关键节点，每个节点有责任方和交付物名称，无空白格子。

### 3. 物料清单与视觉
- **执行方类型**：Canva（邀请函版式）+ 即梦（主视觉生图）
- **一句话验收标准**：物料清单含签到墙、伴手礼、桌卡、H5 邀请函四项；Canva 出一版邀请函可编辑稿，即梦出一张 16:9 主视觉图，少爷审过才算过。

### 4. 风险预案
- **执行方类型**：豆包
- **一句话验收标准**：列出至少 5 项风险（迟到 / 超预算 / 设备故障 / 嘉宾缺席 / 天气或政策变动），每项含触发条件和替代方案，无"加强沟通"这类空话。

## 预计顺序
1. **目标与预算拆解**（串行前置）——后面所有动作都围着 8 万和 200 人转。
2. **分工与排期表**（依赖 1，串行）——排期按目标倒推。
3. **物料清单与视觉**（与 2 的后半段可并行）——物料是执行层，不阻塞排期表本身。
4. **风险预案**（与 3 可并行）——风险预案不依赖视觉稿，但要等排期定稿才好标触发节点。
