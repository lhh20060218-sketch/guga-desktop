# 任务模板：合同要点提炼

## 目标示例

少爷：对方发过来这份 NDA，你帮我把要点和风险点挑出来，今晚我要拍。

## 子任务拆解

1. **喂合同与通读**
   - 执行方类型：少爷（上传合同 PDF）+ Kimi（长文本阅读，吃进整份合同，先做条款级摘要）
   - 验收标准：拿到一份条款清单，每条标"是什么 / 对我方有利还是不利 / 一句话风险提示"；超长合同由咕嘎按章节切片分批喂，避免漏读。

2. **标风险与义务**
   - 执行方类型：DeepSeek（基于条款清单，挑出金额、期限、违约责任、保密义务、终止条款这五类硬条款）+ 咕嘎（逐条核对原文数字与日期）
   - 验收标准：每条硬条款都能在合同原文里定位到段落号；数字、日期、期限不允许 AI 改写，必须照抄；对不上的地方标"待人工复核"，不允许猜。

3. **给少爷决策建议**
   - 执行方类型：咕嘎（整理成"可签 / 需改 / 不建议签"三档建议），少爷（拍板）
   - 验收标准：建议段必须写明"如果签，最担心哪一条 / 如果改，改哪一句 / 如果不签，替代方案是什么"；不允许只写"请少爷审阅"这类空话。

4. **出交付件**
   - 执行方类型：WPS Office（Word 版要点清单）或 Notion AI（在线文档），咕嘎（导出 PDF）
   - 验收标准：交付件 = 一页纸要点 + 一页纸风险清单 + 一页纸建议；少爷 10 分钟内能看完做决定。

## 预计顺序

1. 喂合同与通读 —— 第一步，合同没读完后面全猜。
2. 标风险与义务 —— 串行，等条款清单出来。
3. 给少爷决策建议 —— 串行，风险点没列完不下结论。
4. 出交付件 —— 最后一步，排版导出。
