# deepseek-ask：DeepSeek（网页版）提问取回答

- **剧本ID**：deepseek-ask
- **软件**：DeepSeek 网页版（https://chat.deepseek.com/，本机未装桌面端，以网页版为准）
- **动作目标**：在新会话里输入问题并发送，拿到完整回答

## 前置条件
1. 少爷已在浏览器打开 https://chat.deepseek.com/ 并登录（手机号+短信验证码 / 微信扫码 / 邮箱）。
2. 左侧可见「历史对话」列表、底部可见输入框；若弹登录窗，请少爷本人扫码或收验证码，咕嘎不代读。
3. 网络通畅，页面未卡在加载动画。

## 步骤序列
1. **元素特征**：网址 `https://chat.deepseek.com/`；不在主页则点左上角「新对话」按钮（待真机核对原文）。
   **动作**：进入空白会话。
   **等待判据**：输入框居中出现，占位符「给 DeepSeek 发送消息」（第三方抓取值，待真机核对）。
2. **元素特征**：输入框，占位符「给 DeepSeek 发送消息」。
   **动作**：单击并键入少爷的问题全文。
   **等待判据**：文字逐字上屏；右下角圆形发送按钮由灰转亮（空输入时为禁用态，类名 `ds-icon-button--disabled`，待真机核对）。
3. **元素特征（可选）**：输入框附近「深度思考」开关（官方称「深度思考」/DeepThink 按钮，位置待真机核对）。
   **动作**：推理/数学/代码题先开启；闲聊、改写类跳过。
   **等待判据**：开关呈高亮已开启态。
4. **元素特征**：发送按钮（圆形上箭头图标，无文字，待真机核对），或按回车。
   **动作**：点击发送（或按 Enter）。
   **等待判据**：文字上屏为用户气泡；回答区出现流式文字，「停止生成」按钮出现（待真机核对）。
5. **元素特征**：回答区 Markdown 块（类名 `ds-markdown`，待真机核对）。
   **动作**：等待流式输出跑完。
   **等待判据**：文字停滚，「停止生成」按钮消失，回答底部复制/点赞/分享图标重新出现。

## 成功判据
回答气泡完整呈现，底部操作行图标点亮，页面无「生成失败/网络异常」红字。

## 异常处理
- **未登录**：弹二维码或「手机号/邮箱」输入框 → 停手，请少爷本人登录；回主页后从步骤 1 重走。
- **加载超 60 秒无首字**：少爷，这一答卡了 60 秒，多半高峰排队。咕嘎先点「停止生成」，等 30 秒原样重发；仍卡则关「深度思考」再发。
- **回答中断**（流突然停住、停止按钮不消失）：少爷，答到一半断了。咕嘎补一句「请接着上面继续」让它续写；仍断就换问法重发。
- **弹「服务器繁忙 / Max challenge attempts exceeded」**：官方提示刷新重试。咕嘎 F5 刷新 → 左侧历史还在，点回本条会话继续，不重问。
- **网络异常红字**：断网等少爷连 Wi-Fi；网通仍报错就重开标签页。
- **误发/问错**：点用户气泡下方「…」→「删除」（待真机核对），或左侧会话「…」→「删除」整条重来。
