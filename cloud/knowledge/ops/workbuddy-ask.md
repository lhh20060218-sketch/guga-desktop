# workbuddy-ask：WorkBuddy 桌面客户端 · 新建任务并提问取回答

- **剧本ID**：workbuddy-ask
- **软件**：WorkBuddy 桌面客户端（Windows，V5.9.3，Electron，深色主题）
- **动作目标**：在 WorkBuddy 里新建一个独立任务，发送问题，等到 AI 回答输出完毕
- **验证状态**：2026-11-03 真机实测通过（证据：guga-desktop/evidence/wb-ask_224739.png、wb-ask_final.png）

## 前置条件

1. WorkBuddy 主窗口已打开且已登录（窗口标题恰为"WorkBuddy"）。
2. **必须先点"新建任务"**——绝不能直接在当前会话的输入框打字，那会把消息发进少爷正在进行的对话里（比豆包画布陷阱更严重：WorkBuddy 常驻前台就是聊天界面）。
3. 已登录、网络正常。

## 步骤序列

0. **元素特征**：侧栏顶部"新建任务"按钮（⊕ 图标 + 文字，无快捷键标注）。
   **动作**：单击。
   **等待判据**：界面切换到新任务首页——大标题"WorkBuddy, 我帮你"，屏幕中央出现大输入框（占位符"今天帮你做些什么？@ 添加上下文，/调用技能与指令"），下方有一排场景快捷标签（日常开发/开发网站/小程序/Agent 应用/开发 Skill/技术文档）。**不会弹模板对话框，直接可用（已真机核对）**。

1. **元素特征**：屏幕中央的大输入框（新任务页在屏幕中央，约 x 50% / y 42%；会话页在底部，约 x 31% / y 88%——两处坐标不同，注意区分）。
   **动作**：单击输入框文字行。
   **等待判据**：**该输入框无明显焦点光环（已真机核对），画面校验会漏报——必须以第 2 步粘贴校验为准，不要因焦点校验失败而中断**。

2. **元素特征**：输入框本体。
   **动作**：剪贴板粘贴问题（规避中文输入法），粘贴前后局部截图对比，文字必须真的进了输入框。
   **等待判据**：输入框内出现文字（画面有变化）。

3. **元素特征**：输入框本体（Enter 发送，已真机核对可用；也可点右下角圆形发送按钮）。
   **动作**：按 Enter。
   **等待判据**：界面自动切换到新会话页：标题=问题前缀，用户气泡靠右出现，侧栏任务列表顶部新增该任务条目。

4. **元素特征**：WorkBuddy 的"已处理 Xs / 准备中"状态行 + 回答气泡。
   **动作**：等待回答。
   **等待判据**：⚠️ **WorkBuddy 是 Agent 模式，与普通聊天软件不同（已真机核对）**：回答前有联网搜索/工具调用阶段，画面会出现 10~30 秒的静止（状态行显示"已处理 Xs / 准备中"），随后才流式输出。判停阈值必须放宽到**连续 20 秒无变化**才算结束（普通 8 秒判停会把思考停顿误判为完成）。总耗时参考：简单问答 30~40 秒。

## 成功判据

- 新会话页里"提问 → 回答"成对出现，回答气泡底部工具栏（复制/朗读/点赞等）完整；
- 侧栏任务列表顶部出现以问题命名的新任务条目；
- 旧会话内容零污染（本次实测确认"确定工作台优化方向"会话未受影响）。

## 异常处理

- **粘贴后输入框无变化**：焦点不在输入框（可能停在新任务首页但点到场景标签上）。重新单击输入框文字行（y 42% 处），再粘贴。
- **等待超过 90 秒仍无回答**：Agent 任务可能卡在工具调用。观察"已处理 Xs"计数是否还在增长：在涨就继续等；停住超过 60 秒且无输出，回报少爷，建议少爷本人查看是否需要授权（"允许完全访问"未开启时部分工具会被拦）。
- **误在旧会话输入框打字**：立刻清空（Ctrl+A + Delete），按步骤 0 点"新建任务"重来，不要在旧会话里发送。
- **新任务页点到场景快捷标签**：会预填提示词，清空输入框重新粘贴即可。
