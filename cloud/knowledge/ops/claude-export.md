# claude-export：Claude（网页版）复制 / 导出回答结果

- **剧本ID**：claude-export
- **软件**：Claude 网页版（https://claude.ai/，本机未装桌面端，以网页版为准）
- **动作目标**：把回答取走——用复制按钮单条复制后粘贴到目标应用，或用分享按钮生成整条会话链接

## 前置条件
1. 当前会话里有一条已输出完毕的完整回答（中断按钮已消失、底部图标行已出现）。
2. 目标应用（记事本 / Word / 邮箱 / 飞书）已开好，光标停在要粘贴处。
3. 生成分享链接前，少爷已知情：链接任何人点开都能看到分享那一刻为止的全部聊天快照；分享之后新消息默认仍私有。

## 步骤序列

### 方式 A：单条回答复制（Markdown 进剪贴板）
1. **元素特征**：Claude 的某条回答气泡。
   **动作**：把鼠标悬停（hover）到这条回答上。
   **等待判据**：回答底部浮现一排小图标，其中有复制图标（外观为两个重叠方块，tooltip 原文待真机核对）。
2. **元素特征**：该复制图标。
   **动作**：单击，回答按 Markdown 写入剪贴板。
   **等待判据**：图标短暂变为「已复制」态（打勾之类，待真机核对）。
3. **元素特征**：目标应用输入区。
   **动作**：单击定位，按 Ctrl+V 粘贴。
   **等待判据**：回答连同标题、列表、代码块结构落进目标应用。

### 方式 B：整条会话生成分享链接
4. **元素特征**：聊天窗口右上角「Share」按钮（官方原文：upper right corner 的 "Share" button）。
   **动作**：单击「Share」。
   **等待判据**：弹出 Share 浮层。
5. **元素特征**：弹窗内的「Share」按钮（官方原文：click the "Share" button in the pop out）。
   **动作**：单击弹窗里这个「Share」，生成可分享链接。
   **等待判据**：浮层出现一串 https 链接及复制入口。
6. **元素特征**：生成的链接地址。
   **动作**：点链接旁复制按钮取走链接。
   **等待判据**：粘到浏览器地址栏回车，能打开只读聊天快照页，即链接有效。

## 成功判据
- 方式 A：目标应用 Ctrl+V 后正文完整、结构保留。
- 方式 B：链接在无痕窗口也能打开，展示分享前的聊天快照；想撤销可回同一「Share」菜单取消分享（unshare）。

## 异常处理
- **悬停不出复制图标**：少爷，图标没浮出来。咕嘎把鼠标在回答上来回挪、等整段加载完再悬停；仍不出就改用方式 B 或手动框选 Ctrl+C。
- **粘贴后格式乱**：少爷，纯文本应用不认 Markdown。咕嘎改贴到支持 Markdown 的编辑器，或手动清掉 `#`、`**` 标记。
- **点 Share 没弹窗**：少爷，弹窗被浏览器拦了。咕嘎放行地址栏右侧的弹窗拦截后重试。
- **链接打开是登录墙**：少爷，这分享默认按邮箱邀请特定人、不生成公开链接；要公开需在浮层切到公开选项（开关原文待真机核对）。
- **误把敏感会话公开**：少爷，咕嘎立刻回该会话「Share」→ 取消分享，链接随即失效。
