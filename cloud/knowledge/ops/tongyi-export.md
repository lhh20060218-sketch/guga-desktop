# 通义千问 · 剧本③：复制 / 分享 / 导出回答结果

- **剧本ID**：tongyi-export
- **软件**：通义千问（桌面客户端 + 网页版）
- **动作目标**：把千问的回答复制到剪贴板、或把整个会话生成分享链接、或导出到本地文件

## 前置条件

1. 对话已完成，目标回答气泡在消息流中可见，末尾操作按钮行已浮出。
2. 若要分享或导出，该对话必须是**正式对话**（不是【临时对话】——临时对话退出即销毁，无法分享/导出）。

## 步骤序列

### A. 复制单条回答

1. **元素特征**：回答气泡末尾的【复制】按钮（叠纸图标，与点赞/点踩/重新生成同排；悬停回答才会浮现，按钮图标形态**待真机核对**）。**动作**：鼠标悬停在目标回答上，等按钮行完全浮现后单击【复制】。**等待判据**：按钮短暂变为"已复制"勾选态（**待真机核对**），系统剪贴板已装入该回答全文。
2. **动作**：切到目标应用（Word / 记事本 / 微信输入框），按 Ctrl+V 粘贴。**等待判据**：目标位置出现完整回答文本。

### B. 把整个会话分享为链接

1. **元素特征**：回答末尾的分享按钮（将对话以链接形式分享），或左侧"对话历史记录区"中悬停该条记录 → 更多菜单（…）里的【分享此对话】。**动作**：单击。**等待判据**：弹出分享对话框并生成链接，出现"复制链接"入口（对话框具体文案**待真机核对**）。
2. **动作**：复制链接，粘贴到目标聊天工具。**等待判据**：链接对方可打开并看到该对话内容。

### C. 导出会话到本地

1. **元素特征**：左侧"对话历史记录区"，悬停目标对话 → 更多菜单（…）→【导出会话】。**动作**：单击。**等待判据**：客户端/浏览器弹出保存对话框，或开始自动下载（导出文件格式 md/txt **待真机核对**）。
2. **动作**：选择保存路径后确认。**等待判据**：下载完成，本地出现导出文件，打开后内容与对话一致。

> **如实说明**：通义千问 C 端官方提供的是单条【复制】、会话【分享此对话】（链接）、【导出会话】三项；**没有**"一键导出为 Word/PDF"的固定菜单项。若需要 Word/PDF，请走 A：复制文本粘贴进 Word 再另存，或用浏览器"打印 → 另存为 PDF"。

## 成功判据

目标应用中出现完整回答文本，或目标位置出现可打开的分享链接、或本地出现可正常打开的导出文件。

## 异常处理（管家口吻）

- **点【复制】后粘贴为空**：少爷，多半是按钮没点中，重新悬停回答、等按钮行完全浮现再点一次。
- **分享链接打不开/提示无权限**：该会话若是在【临时对话】下生成的，无法分享，请回正式对话里操作。
- **导出失败或找不到文件**：检查下载目录权限，改存桌面；网页版若被浏览器拦截弹窗，允许弹窗后重试。
- **粘贴后格式丢了**：代码块、表格、列表粘进纯文本编辑器会乱排版，少爷请粘到 Word 或支持 Markdown 的应用里再排版。
