# copilot-ask：Copilot 提问取回答

- **剧本ID**：copilot-ask
- **软件**：Microsoft Copilot（Windows 桌面客户端，copilotapp.exe，版本 156.0.4314.58）
- **动作目标**：在 Copilot 客户端中输入一个问题并发送，等待 AI 生成完整回答

## 前置条件

1. Copilot 客户端已安装并正在运行：进程 `copilotapp.exe`，路径 `C:\Program Files (x86)\Microsoft\Copilot\Application\copilotapp.exe`（2026-11-03 本机实测）。
2. 已用 Microsoft 账户（MSA）或 Microsoft Entra ID 登录；未登录时界面停在登录引导页（来源：新浪科技 2023-09-27、掘金 2023-12-10，均证实需微软账号登录）。
3. Copilot 窗口已打开并处于前台，能看到底部的文本输入框。
4. 网络可访问 Copilot 服务（国内需网络条件支持，来源：掘金 2023-12-10）。

## 步骤序列

1. **元素特征**：窗口底部的文本输入框，占位符历史文案为「向我提问吧」/「Ask me anything」（来源：中国新闻网 2023-02-08 报道；当前桌面客户端占位符待真机核对）。**动作**：点击输入框获得焦点，输入问题文本，例如「帮我写一段周报开头」。**等待判据**：输入框内出现光标，文字已填入且不被截断。
2. **元素特征**：输入框右侧的发送按钮，通常为箭头/纸飞机图标（图标原文待真机核对；网页版 historically 以箭头按钮发送，来源：中国新闻网 2023-02-08）。**动作**：点击发送按钮（或按 Enter）。**等待判据**：输入框文字清空，对话区上方出现用户问题气泡，回答区域开始出现加载动画/光标。
3. **元素特征**：回答区域，位于对话区中上段，Copilot 头像旁的文本气泡。**动作**：等待回答生成完毕，不操作。**等待判据**：回答文本停止滚动/打字动画消失；回答下方出现操作工具栏（含复制、点赞、点踩等图标，具体文字待真机核对）。若超过 60 秒仍在加载，按异常处理走。
4. **元素特征**：回答区域末尾。**动作**：肉眼确认回答完整。**等待判据**：回答末尾无「正在生成…」「停止」按钮残留，文本结束在句号/换行。

## 成功判据

- 对话区中出现一条完整的 Copilot 回答气泡，内容与问题相关，回答下方操作工具栏已出现。

## 异常处理

- **未登录**：少爷，界面停在「登录/Sign in」页（按钮原文待真机核对），点登录按钮跳微软账号登录窗口，完成密码或扫码后回到 Copilot 窗口，从步骤 1 重走。
- **加载超过 60 秒**：少爷，先看是否有「停止生成/Stop」按钮（待真机核对）并点击停止；再查网络（托盘看是否断网），恢复后重新发送同一问题。
- **网络异常/报错弹窗**：少爷，出现「出错了/Error」提示（原文待真机核对）就点关闭，等 5 秒重发；连续 3 次失败换网页版 https://copilot.microsoft.com/ 兜底。
- **回答中途中断**：少爷，回答生成一半停了，在输入框补一句「继续」，同一会话内让 Copilot 接着写。
- **弹广告/推广横幅**：少爷，点右上角 × 关闭（待真机核对），不影响主流程。
- **输入框无反应**：少爷，点输入框不亮光标说明窗口没聚焦；先点 Copilot 窗口标题栏再点输入框。
