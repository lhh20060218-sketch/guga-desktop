# deepseek-export：DeepSeek（网页版）复制回答 / 生成分享链接 / 导出历史

- **剧本ID**：deepseek-export
- **软件**：DeepSeek 网页版（https://chat.deepseek.com/）
- **动作目标**：拿到当前回答——① 复制单条文本；② 整条对话生成公开分享链接；③（兜底）导出全部历史。官方无「单条一键导出 .md」，单条走「复制 → 粘贴到目标应用」。

## 前置条件
1. 当前会话已有完整回答并输出完毕（底部图标已点亮）。
2. 少爷说清走哪条：进 Word/记事本 →①；发给别人看整段对话 →②；全盘备份 →③。
3. 目标应用（微信/飞书/Word/记事本）已打开并停在可粘贴位置。

## 步骤序列

### 路径① 复制单条回答
1. **元素特征**：回答气泡右下角复制图标（第三方称「答案右下角图标」，外观待真机核对）。
   **动作**：点复制图标；代码块点其右上角自带「复制」按钮（官方：代码块可直接复制、表格可复制/下载）。
   **等待判据**：出现「已复制」toast 或图标变勾（待真机核对）。
2. **动作**：切到目标应用 Ctrl+V。
   **等待判据**：粘贴文字与正文一致，代码块缩进、标题层级没糊。

### 路径② 生成整段对话分享链接
1. **元素特征**（任选其一，官方核实存在）：回答下方「分享」按钮；左侧该条旁「…」→「分享」；页面右上角「分享」按钮。
   **动作**：点击其一。
   **等待判据**：弹出分享面板，含「生成链接」「生成图片」选项（原文待真机核对）。
2. **元素特征**：面板里「生成链接」。
   **动作**：点击生成。
   **等待判据**：出现 `https://chat.deepseek.com/share/...` 链接并自动入剪贴板（待真机核对）。
3. **动作**：发链接给少爷或贴目标应用；同时提醒两点官方声明——(a) 分享不含上传文件；(b) 将来删本对话，此链接立即失效。

### 路径③ 导出全部历史（仅网页端）
1. **元素特征**：左侧边栏「设置」入口（待真机核对）。
   **动作**：「设置」→「数据管理」→「导出所有历史对话」（官方 FAQ 路径）。
   **等待判据**：出现生成提示并给出下载链接。
2. **动作**：点下载，存到少爷指定文件夹。
   **等待判据**：浏览器下载完成；官方称链接 7 天有效，过期须重导。

## 成功判据
① 目标应用粘贴出完整正文；② 剪贴板有 `chat.deepseek.com/share/` 链接且无痕窗口能打开同段对话；③ 得到一个导出文件包。

## 异常处理
- **复制没反应 / 粘贴为空**：少爷，复制图标抽风。咕嘎改为在回答里从首字拖选到末字，Ctrl+C / Ctrl+V；代码块过长单独复制代码块。
- **分享链接打开空白/404**：多半对话已删或未生成完。咕嘎等 5 秒重「生成链接」；仍 404 退回复制方案。
- **想单条导出 .md 文件**：官方没此入口。少爷，DeepSeek 不提供单条 Markdown 导出，咕嘎按①复制全文，粘到本地 `.md` 记事本存盘，效果等价。
- **「设置」找不到「数据管理」**：先刷新到最新；仍无请少爷确认是否游客态（未登录无可导出数据），登录后再走③。
- **导出迟迟不到 / 链接过期**：官方给 7 天有效期。咕嘎重新点「导出所有历史对话」，并提醒少爷导出文件含全部对话与账号信息，勿外发。
