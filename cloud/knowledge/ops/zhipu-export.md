# zhipu-export：智谱清言复制回答 / 分享 / 导出结果

- **剧本ID**：zhipu-export
- **软件**：智谱清言（桌面客户端 / 网页版 https://chatglm.cn）
- **动作目标**：把 AI 回答以"复制 / 分享链接 / 落到本地文档"三种方式之一带走。

## 前置条件

1. 已完成 `zhipu-ask` 或 `zhipu-followup`，聊天区至少一条已完成流式输出的 AI 回答气泡（底部图标栏已现）。
2. 账号已登录，网络正常。
3. 已选形态：A 单条文本→复制；B 整段对话外发→分享链接；C 要 Word/PDF→官方不提供原生导出，走"复制+粘贴到 Word/飞书"兜底。

## 步骤序列

### 路线 A：复制单条回答

1. **定位目标气泡**
   - 元素特征：聊天区目标 AI 回答气泡（左对齐）。
   - 动作：鼠标悬停到该气泡。
   - 等待判据：气泡下方浮出图标工具栏（复制、重新生成、点赞/点踩、分享等，顺序与 tooltip 原文待真机核对）。

2. **点复制图标**
   - 元素特征：工具栏"复制"图标（两张重叠纸张；tooltip 原文待真机核对）。
   - 动作：单击。
   - 等待判据：出现"已复制"toast（文案待真机核对），剪贴板拿到回答文本/Markdown。

3. **粘贴到目标应用**
   - 元素特征：记事本/Word/飞书/微信输入框编辑区。
   - 动作：切到目标应用，点编辑区，Ctrl+V。
   - 等待判据：回答正文出现；不支持 Markdown 的应用里 `**`、`#` 属正常。

### 路线 B：生成分享链接

4. **点分享图标**
   - 元素特征：同一条气泡工具栏"分享"图标（向外箭头/链接样式，tooltip 原文待真机核对）。
   - 动作：单击。
   - 等待判据：弹出分享浮层，含"生成链接/复制链接"按钮（原文待真机核对），可能有"是否允许对方看完整对话"开关。

5. **确认并复制链接**
   - 元素特征：浮层"生成分享链接 / 复制链接"按钮。
   - 动作：点生成 → 链接以 `https://chatglm.cn/share/xxxx` 出现（前缀待真机核对）→ 点"复制链接"。
   - 等待判据：toast 提示"链接已复制"，剪贴板拿到 https 链接。

### 路线 C：官方无一键导出时的兜底

6. **逐条复制整段对话**
   - 元素特征：每条 AI 回答气泡的"复制"图标（同步骤 2）。
   - 动作：从最早一条 AI 回答开始，逐条悬停→点复制→切到 Word/飞书→Ctrl+V，空行隔开；用户提问也一并复制。
   - 等待判据：目标文档自上而下复现整段对话，无缺轮次。
   - **如实说明**：App/桌面端不开放"一键导出整段对话为文件"（第三方教程："App 端不开放批量导出接口，必须单条点选"）；批量导需另装浏览器插件。

## 成功判据

- 路线 A：Ctrl+V 后回答正文完整、代码块缩进没乱。
- 路线 B：链接粘到浏览器无痕窗口能看完整只读页，无需登录。
- 路线 C：Word/飞书文档里对话按时间顺序齐整，抽查首尾与界面一致。

## 异常处理（管家口吻）

- **点复制但粘贴是空的**：少爷，toast 没出就切走了。回智谱再点"复制"，等"已复制"提示再切。
- **代码块复制后缩进乱**：从代码块左下角拖到右上角单独 Ctrl+C。
- **分享按钮没反应 / 提示"该内容不支持分享"**：敏感词或被风控，改路线 A。
- **链接打开要登录**：分享默认"仅登录用户可见"。回浮层把"公开可见"开关打开（原文待真机核对）。
- **toast 报"网络异常，分享失败"**：等 10 秒再点；连试 3 次失败改路线 A。
- **没有"导出"按钮**：少爷这不是 bug，官方没做，按路线 C 复制。
- **客户端崩溃**：记录在云端，重启或开 chatglm.cn 即恢复。
