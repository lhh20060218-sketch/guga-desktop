# 运行、部署与排查

三端可以分开跑，也可以只跑你关心的那一端。

---

## 一、云端大脑（Node.js）

```bash
cd cloud
cp .env.example .env      # 填写 LLM_API_KEY（OpenAI 兼容接口）
npm install
npm start                 # 默认 3000 端口
```

`.env` 关键项：

| 变量 | 说明 |
|---|---|
| `LLM_BASE_URL` | OpenAI 兼容接口，如 `https://open.bigmodel.cn/api/paas/v4` |
| `LLM_API_KEY` | 只放服务端，前端永远拿不到 |
| `LLM_MODEL` | 如 `glm-4-flash` / `deepseek-chat` / `qwen-plus` |
| `JUDGE_USER` / `JUDGE_PASS` | 演示账号；**不设置密码时启动会随机生成并打印一次**，源码里不含默认弱口令 |

生产部署（Linux）：

```bash
npm i -g pm2
pm2 start server.js --name guga
pm2 save && pm2 startup
```

> 务必用 `nginx` 或安全组限制来源，不要把 3000 端口裸暴露到公网。

## 二、桌宠端（Python / PyQt5）

```powershell
pip install -r requirements.txt
copy ai_config.example.json ai_config.json   # 填对话 API（与云端可以不是同一家）
python comp_main.py                          # 参赛版：管家形态
python launcher.py                           # 开发版：完整能力
```

- 需要 Windows 10/11 + Python 3.10+（推荐 3.12）
- `ai_config.json` 已在 `.gitignore` 中，不会被误提交
- `run_as_admin` 默认 `false`；仅在使用需要提权的系统级操作时才改为 `true`

## 三、真机执行本体（Python）

```powershell
cd agent
pip install -r requirements.txt
python preflight.py              # 18 项体检，先确认这台机器能不能真机干活
python guga_agent.py <配对码>     # 配对码在云端 Web 端"自检"弹窗生成
```

`preflight.py` 检查什么（判定标准：**0 FAIL**；WARN 属于知情可用，不影响发布）：

- Python 版本与依赖（pyautogui / pyperclip / pygetwindow / Pillow）
- DPI 感知级别与截图尺寸是否一致
- 送视觉模型的图宽是否足够（满屏正文 ≥ 7px 才算可靠）
- 目标软件是否安装、进程能否枚举、窗口能否唤到前台
- 托盘是否会把窗口藏起来

**换成自己的服务端**：设环境变量 `GUGA_CLOUD`，如

```powershell
set GUGA_CLOUD=http://你的服务器:3000
```

## 四、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 点击整体偏移 / 只截到窗口左上角 | 进程 DPI 感知不是 per-monitor | 显示缩放设为 100%，或按 `preflight` 提示排查 |
| 视觉说"看不到按钮" | 送模型图太小，正文糊成一团 | 把目标软件窗口拖窄到 1500px 内，执行器会自动区域放大兜底 |
| 提示"软件没开"但任务栏有图标 | 窗口被托盘隐藏，`pygetwindow` 只枚举可见窗口 | 执行器已内置托盘唤醒；若仍失败，手动点开一次再跑 |
| 置前失败 | Windows 前台锁定静默拒绝 | 执行器会注入一次 Alt 伪造输入再置前；仍失败请手动点一下目标窗口 |
| 截图截到别的软件 | 多个 AI 窗口位置几乎重叠 | 执行器强制置前并校验句柄；仍异常请把两个窗口分开摆放 |
| 配对成功但一直没单 | 云端台账里任务未派给这台设备 | 在 Web 端确认任务归属与设备在线状态 |

## 五、验收证据怎么看

云端 Web 端有"证据墙"：每条任务下挂着执行过程中的截图与步骤回执。

复核顺序建议：
1. 看任务拆解——子任务与验收标准是否合理
2. 看证据截图——每一步是否真的点到了正确位置
3. 看裁决记录——不合格时是否真的打回，而不是自我通过
