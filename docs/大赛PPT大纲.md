## P8 · （三）分析方法选择（1 页）

- **一句话**：不是选最先进的技术，是选在这批软件上真能跑通的那条。
- **画面**：四条路线对比表 + 选择依据 + 适配场景优势

  | 路线 | 可得性 | 稳定性 | 覆盖 | 结论 |
  | --- | --- | --- | --- | --- |
  | API 直连 | 三家均无对外文本 API | 高 | 极低 | 不可作为主路径 |
  | MCP 指挥 | 三家都是 client 方向，无 server | 高 | 极低 | 只能做「发现」 |
  | 纯视觉坐标 | 不依赖接口 | 低（缩放/改版即偏） | 中 | 只作兜底 |

- **选择依据**：场景（办公软件大多不开放接口，界面是唯一公共面）／风险（单信号不可信）／验收（没有回执不算完成）。
- **适配场景优势**：零改造接入、跨软件通用（只加一份 JSON）、可审计（截图 + 双哈希 + 失败码）。
