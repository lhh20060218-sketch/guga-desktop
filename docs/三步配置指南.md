# 咕嘎桌宠 · 三步配置指南（写给第一次用的人）

不需要懂编程，不需要会改文件，跟着点鼠标就行。全程约 3 分钟。

---

## 第 0 步：解压

把下载的 `GUGA-Desktop-win64.zip` 解压到**任意文件夹**（桌面也行）。

解压完你会看到：

```
GUGA-Desktop\           ← 这个文件夹整体，别拆散
   GUGA-Desktop.exe     ← 企鹅在这里
   _internal\           ← 它的"身体"（别删别改名）
```

---

## 第 1 步：双击 GUGA-Desktop.exe

第一次启动会**自动弹出配置向导**（因为还不知道要用哪家 AI）。
你不需要打开任何文件、不需要改任何代码——向导里点选就行。

---

## 第 2 步：在向导里填三样东西

### ① 对话 API（必填，咕嘎的大脑）

1. 「平台」下拉框选一家 —— **推荐智谱 GLM**（有免费额度，注册最快）
2. 点向导里的「去申请 Key」链接 → 注册 → 在控制台生成一个 API Key → 复制
3. 回到向导，把 Key 粘贴进「API Key」框（钥匙形状的小输入框）
4. 点 **「测试连接」**——看到 ✅ 绿勾就说明填对了；红叉会告诉你错在哪

> 智谱免费额度就够日常用；想换 DeepSeek / 通义，下拉框里都有，步骤完全一样。

### ② 云端大脑（选填，填了解锁管家派单 + 跨设备）

- 在「账号」「密码」里填**作品材料页提供的演示账号**
- 点「测试登录」，✅ 后你就有：说目标 → 派单 → 监工台账 → 验收播报
- **不填也能用**：桌宠的对话、语音、游戏军师都正常，只是没有云端派单

### ③ 点「保存并启动咕嘎」

向导自动生成配置文件并关闭，企鹅出现在你的桌面上。

---

## 第 3 步：跟它说话

- **左键双击企鹅**（或右键菜单「对话」）→ 打字提问，它会回答并朗读
- **右键企鹅**：
  - 「🗣️ 派个任务…」——说一个目标（如"把这份资料整理成周报要点"），它拆解、派单、监工、验收，全程语音播报
  - 「📋 任务台账」——看每个子任务的实时进度和验收结果
  - 「👔 管家与员工」——召唤学者/军师等分身
- **数字键 1 / 2 / 3**：请教助教 / 助教出题 / 语音对话

---

## 常见问题

| 现象 | 解决 |
|---|---|
| 双击没反应 | 确认解压了整个文件夹（`_internal` 必须和 exe 在一起）；被杀毒软件拦就点"允许" |
| 测试连接红叉：401 / 密钥错误 | Key 复制不完整或选错平台——重新复制，或换一家平台 |
| 测试连接红叉：超时 | 网络问题，重试一次；公司内网可能拦截 API |
| 想改配置 | 删掉 `_internal\ai_config.json`，重新双击 exe，向导会再来一次 |
| 我没有任何 API Key | 用作品材料页的**在线体验链接**（浏览器打开就能玩，什么都不用配） |
| 派单后一直"排队中" | 本机执行需要任务目标里提到的 AI 软件已安装（豆包/Kimi 等）；或换"打开记事本写…"这类本机任务 |

## 隐私说明

- API Key 只保存在你电脑的 `_internal\ai_config.json`，不上传、不进代码仓库
- 微信 / 企业微信 / QQ 被咕嘎主动拒绝接管（读屏会看到私人聊天，这不体面）
- 每次执行都有截图留痕，可在台账里回看它做了什么
