## 二、视觉特征（逐字抄录界面原文）

### empty_chat
- 主区居中蓝白渐变 logo，下方大号「**今天有什么工作要处理？**」（`doubao-empty_chat-1.png`）
- 其下「**对话**」「**工作**」两个圆角 tab，「工作」默认高亮。
- 下方「**为你推荐**」列 4 条（本轮可见：「打开<图标>，用豆包处理」「万能攻略 帮我做一份游戏攻略」「行业分析报告 文化旅游行业有哪些机会和风险」「财富规划 帮我做一份财富规划」）。
- 底部输入框占位「**发消息或创建任务... / 使用技能 @ 添加资料**」，下方按钮行「**+ 本地电脑 项目 按需确认 技能 插件**」，右侧「**自动 低**」。

### ongoing_chat
- 主区连续消息：用户消息为深色块，AI 回复为长文本段（可用 `<•>` 分段标题 + 正文），中间夹富媒体卡片（`doubao-ongoing_chat-1.png`）。
- 顶部中央会话标题（如「队友知识库制作要求 >」），下方小字「AI 生成可能有误 请核实」。
- **右侧栏四段式面板**：`对话摘要` → `工作进度`（带 ✅ 勾选列表）→ `相关记忆` → `对话产物`（文件卡片 +「查看更多」）→ `对话资源`。
- 输入框占位同 empty_chat，但左侧多了「+」与模式按钮组；右侧有「自动 低」档位与发送圆钮。

### history_sidebar
- 左栏顶部「豆包」品牌 + 返回/前进箭头 + 搜索放大镜。
- 导航项（自上而下）：**新工作任务**（右侧标 `Ctrl N`）、**新对话**、**定时任务**、**插件·技能·伙伴**、**云盘**、**手机遥控电脑**、**API 服务**（带外链箭头）、**更多**（带展开箭头）。
- 「**项目**」区：只有「**创建新项目**」一行，无项目列表时为空。
- 「**最近**」区：倒序会话列表（标题截断式），底部为用户头像 +「体验套餐」。

### dialog_popup
- 内置浏览器顶栏：「豆包浏览器 不是您的默认浏览器」+「**设为默认**」按钮。
- 右侧卡片：「**添加为桌面快捷方式** / 想更便捷地使用 AI 浏览器？建议添加桌面快捷方式。」+「**暂不添加**」「**立即添加**」。
- 服务通知页：福利/额度类推广文案 + 链接。

### unknown
- 既不满足上述任一特征、窗口标题仍以「豆包」开头 → unknown。

### loading / ai_creation_page
- `loading`：本轮无实测图，不做形态断言。
- `ai_creation_page`：不出现（理由见第一节）。

## 三、会话 / 项目结构说明

1. **有无工作空间 / 项目概念**：有「项目」，但**不是工作空间选择页**。左栏「项目」区仅「创建新项目」入口，点击后主区不跳独立项目列表（上一轮实测像素差异 1.43%）。判 `workspace_picker` 前必须确认主区真的出现了"请选择项目/工作区"的列表页，仅看到侧栏「项目」二字**不算**。
2. **历史列表在哪**：左栏「最近」区，倒序，标题截断；当前会话高亮；条目右侧有时钟/删除图标。
3. **怎么区分"进行中的重要项目"vs"随便聊的旧会话"**：**外观不可判**。没有星标、没有项目归属徽标；但 `ongoing_chat` 的右侧「工作进度」面板能反映"这单是不是在跑"——有勾选列表/进度条即视为进行中。
4. **新建会话按钮**：左栏第二行「**新对话**」（对话气泡图标）；另有第一行「**新工作任务** Ctrl N」（任务型会话）。变体：空会话页的「对话 / 工作」双 tab 决定落在聊天还是任务模式。

### 输入区按钮的确切实义（2026-11-06 本轮实测补充）

**豆包有"两套输入区"，按钮完全不同，必须先认出是哪套**：

| 布局 | 判据（输入框下方按钮行原文） | 占位符 |
|---|---|---|
| **工作/任务模式** | `+` ｜ `本地电脑` ｜ `项目` ｜ `…` ｜ `自动 低` ｜ 发送圆钮 | `发消息或创建任务... / 使用技能 @ 添加资料` |
| **对话模式** | `+` ｜ `对话` ｜ `技能` ｜ `快速` ｜ 麦克风 | `发消息或按住空格说话...` |

工作/任务模式下逐个按钮：

| 按钮 | 实测行为 | 是否文件入口 |
|---|---|---|
| `+` | 【2026-11-06 再测】两种布局各点一次，均无浮层、画面无变化 | **否** |
| `本地电脑` | 模式开关（已选中态） | 否 |
| `项目` | 下拉，挂接/切换项目 | 否 |
| `…` | **展开两级菜单**，两项原文：`技能` ｜ `插件`（各带 `>` 子级箭头）——`doubao-menu_more-1.png` | 否 |
| `按需确认` | 权限确认策略（旧版独立成键，本轮已收进 `…`） | 否 |
| `自动 低` | 模型/思考档位 | 否 |

**「技能」点开是什么**（`doubao-skill_page-1.png`）：一个**技能挑选面板**，不是文件选择器。实测分组与原文：`推荐 (2)` → `可视化`（"将数据、流程、机制、架构、关系和时线转成 E…"）、`定时任务`（"创建、查看、更新或删除定时任务"）；`快捷功能 (6)` → `用量`、`技能管理`、`计划`（带"新"标，副文"描述你的任务，执行前会先输出计划"）+ `查看全部`；`办公 (10)` → `PPT`（"帮你生成、编辑和美化 PPT"）、`会议`（"帮你查询会中实时信息、会议记录与产物"）、`录音转写`（"帮你录音，可用于记录面聊或会议，生成摘要、…"）；底部 `搜索...`。
→ **结论：`技能` 和 `插件` 都是"能力选择器"，面板里没有任何"上传文件 / 添加附件"条目。**

**点左栏「最近」条目的实测结果**：**能打开**（本轮点「主对话」后，标题由「队友知识库制作要求 - 豆包」变为「主对话 - 豆包」，主区换成该会话）。这点与元宝相反（元宝点了打不开）。
**副作用**：切到较老会话时主区可能出现「**暂不支持该消息类型**」——老消息里的多媒体格式当前版本读不出（`doubao-chat_mode-1.png`）。不是报错，继续用输入框即可。

**窗口标题随会话变**：形如「{会话名} - 豆包」，只能用来确认"是不是豆包"，**不能用标题判断当前在哪条会话**。
