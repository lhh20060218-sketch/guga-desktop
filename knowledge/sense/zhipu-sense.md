## 二、视觉特征（逐字抄录）

### empty_chat
- 主区居中大号「**画地为牢一天，不如问我一句 😊**」，右上金色 badge「**金融 专家**」+「查看详情 GOOO」（`zhipu-empty_chat-1.png`）。
- 输入框占位「**处理复杂工作**」；框内一行：「**+**」「**对话** / **任务**」（任务高亮）「**GLM-5.3 极致** ⌄」+ 麦克风 + 发送圆钮。
- 输入框下方「**选择分组**」（文件夹图标）；再下方四个分组入口「**PPT制作**」「**研究报告**」「**数据分析**」「**网站制作**」。
- 左下角常驻「**+200** / 今日登录奖励积分」卡片；底部「积分 398.01」（本轮读数，积分随日变化，不得当作固定锚点）。

### ongoing_chat
- 顶部标题栏显示「**[任务] 自我介绍**」，右上角「**工作区**」按钮。
- 主区消息流：AI 侧以「GLM」开头，按「文档与写作 / 数据与分析 / 开发与技术 / 信息与检索 / 创意与多媒体」分段，段内圆点列表。
- 消息底部小图标行：复制 / 重新生成。

### workspace_picker
- 「**选择分组**」展开后四项：「PPT制作」「研究报告」「数据分析」「网站制作」（`zhipu-workspace_picker-1.png`）。
- 性质：这是**任务模板分组**，不是文件/项目工作区。判 `workspace_picker` 时应理解为"分组选择器"，而不是"选一个项目文件夹"。

### history_sidebar
- 顶部 logo「智谱清言」+ 布局切换图标。
- 导航：「**新建任务**」「**Skills 技能**」「**工具箱**」。
- 「**分组**」（右侧 ＋）、「**示例**」。
- 「**最近**」：本机只有「[任务] 自我介绍」。
- 底部：头像 + 积分。

### dialog_popup
- 左下角深色圆角卡片：大字「**+200**」+「**今日登录奖励积分**」+ 右上 ×。
- 性质：角落浮层，不遮挡主操作区；本机实测点 × 一次未必关闭，需再点一次或等其自动消失。

### unknown / loading / ai_creation_page
- unknown：不满足上述任一特征且标题为「智谱清言」。
- loading：无实测形态。
- ai_creation_page：不出现。

## 三、会话 / 项目结构说明

1. **有无工作空间/项目概念**：只有「分组」——四种任务模板（PPT制作/研究报告/数据分析/网站制作），加左栏可自建分组。**不是文件级工作空间**；「选择分组」展开页可视为本软件的 `workspace_picker` 形态（模板选择）。
2. **历史列表在哪**：左栏「最近」，倒序，条目形如「[任务] 自我介绍」。
3. **怎么区分"进行中的重要项目"vs"随便聊的旧会话"**：**部分可判**——任务型会话标题带「**[任务]**」前缀，普通对话无前缀；但"重要与否"仍不可判，必须问用户。
4. **新建会话按钮**：左栏第一行「**新建任务**」（打勾清单图标）。另有输入框内「对话 / 任务」模式开关，决定普通聊天还是任务型。

### 输入区「+」实测（P1 复核项）

- 本轮对 empty_chat 的「+」共点 3 次（含"先移开指针再回到按钮"与"先点标题栏激活"两种手法），**均未弹出「上传文件或图片 / 联网搜索」浮层**，画面无变化（`zhipu-empty_chat-1.png` 即点击后画面）。
- 上一轮同样未触发，只在文档里以"需先聚焦输入框才弹浮层"的经验记录存在。
- **结论（如实）**：智谱「+」浮层在本机**未取得实测截图**，档案中不写"浮层两条原文"为已证事实，改为"待补测"，并提示执行器：若「+」无反应，改用**拖拽文件到输入框**或**直接粘贴文件**作为兜底。
