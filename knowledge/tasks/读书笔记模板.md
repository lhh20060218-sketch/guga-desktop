# 任务模板：读书笔记

## 目标示例

少爷：这本《XXX》我两周后要在团队里分享，你帮我把它读成一份能讲 20 分钟的笔记。

## 子任务拆解

1. **喂书与通读**
   - 执行方类型：少爷（提供 PDF / EPUB / 微信读书导出的划线与批注）+ Kimi（长文本阅读，吃进整本书，先做章节级摘要）
   - 验收标准：拿到一份章节摘要清单，每章 100 字以内说清核心论点；Kimi 一次读不动的超长章节由咕嘎按章节切片分批喂，避免漏读或截断。

2. **提炼金句与论据**
   - 执行方类型：豆包 / DeepSeek（基于章节摘要，挑出 5–10 句最能代表作者观点的原文金句，每条配一个书中论据或案例）
   - 验收标准：金句必须原文照抄，不得润色改写；论据能在原书页码或章节里被咕嘎对到；少爷觉得"不对味"的金句当场删，不凑数。

3. **形成个人观点**
   - 执行方类型：少爷（结合自身工作或行业说一句"这本书对我有什么用"）+ 咕嘎（把少爷这一句扩成三段：同意什么 / 反对什么 / 怎么用）
   - 验收标准："个人观点"一节不能全是作者复述，必须有少爷自己的判断，哪怕只是一句"我不同意第 7 章的前提"；AI 不得替少爷编观点。

4. **输出成稿**
   - 执行方类型：Notion AI（排版成可分享笔记）或 WPS Office（Word 版），咕嘎（导出 PDF / 链接发给少爷）
   - 验收标准：笔记结构 = 一句话总结 + 章节摘要 + 金句摘录 + 个人观点 + 行动清单（读完打算做的 3 件事）；能直接拿去做 20 分钟分享提纲，不用再返工。

## 预计顺序

1. 喂书与通读 —— 第一步，书没喂进去后面全空。
2. 提炼金句与论据 —— 串行，等章节摘要出来再挑。
3. 形成个人观点 —— 串行，这步必须少爷亲口说，AI 不能替他表态。
4. 输出成稿 —— 最后一步，少爷过目后再排版导出。
