# 任务模板：简历优化

## 目标示例
少爷：我要跳槽应聘高级产品经理，目标年薪 60 万，你帮我把现在这版简历改一版，下周一要投出去。

## 子任务拆解

### 1. 读 JD 提取关键词
- **执行方类型**：豆包
- **一句话验收标准**：从少爷给的 3 份目标 JD 里提取高频关键词（如"数据驱动""从 0 到 1""带过 10 人团队"），输出词频表，少爷确认哪些词必须出现在简历里。

### 2. 经历量化改写
- **执行方类型**：Claude
- **一句话验收标准**：把简历里每段经历改写成"动作 + 量化结果"句式（如"主导 X 项目，使次日留存从 30% 提升至 45%"），至少改写 5 条，无"参与了""协助"这类弱动词。

### 3. 排版与 PDF 导出
- **执行方类型**：Canva 或 WPS Office
- **一句话验收标准**：单页或双页 A4，字体统一（≤ 2 种）、行距一致，导出 PDF 后无文字溢出、无空白半页、无图片错位。

### 4. ATS 可读性检查
- **执行方类型**：咕嘎
- **一句话验收标准**：另存一份 .txt 纯文本版本，确认关键经历、公司名、时间段能被完整提取（即 ATS 系统读得懂），少爷终审后投递。

## 预计顺序
1. **读 JD 提取关键词**（串行前置）——不看 JD 改简历就是自说自话。
2. **经历量化改写**（依赖 1，串行）——改写要对齐关键词。
3. **排版与 PDF 导出**（依赖 2，串行）——内容定了才排。
4. **ATS 可读性检查**（依赖 3，串行收尾）——PDF 排好后才测纯文本提取。
