# 任务模板：短视频脚本

## 目标示例

少爷：下周一要发一条 60 秒产品口播，你给我写脚本 + 分镜，周末前过一遍。

## 子任务拆解

1. **定钩子与卖点**
   - 执行方类型：少爷（说清产品最想打的一个卖点、目标人群是谁）+ 豆包（基于卖点生成 5 个开头钩子）
   - 验收标准：钩子 3 秒内必须抛冲突或利益点，少爷从中挑 1 个；一条视频只讲 1 个卖点，不允许塞三个。

2. **写口播稿**
   - 执行方类型：豆包 / 文心一言（按挑中的钩子写 60 秒口播，约 180–220 字）
   - 验收标准：稿子按"钩子→痛点→解决方案→行动号召"四段，每段标注时长；口播像说话不像念稿，少爷试念一遍不卡壳、不绕口。

3. **拆分镜**
   - 执行方类型：咕嘎（把口播稿拆成 4–6 个镜头，每镜写清画面、景别、字幕）+ 即梦 / 可灵（如需空镜或产品演示参考画面，生成素材参考）
   - 验收标准：每个镜头 ≤ 15 秒，画面描述能直接交给拍摄的人照着拍；字幕不超过 12 字一行，不堆字。

4. **成品与审片**
   - 执行方类型：咕嘎（把脚本 + 分镜整理成一页纸交付），少爷（试拍一版或直接定稿）
   - 验收标准：一页纸脚本表 = 镜号 / 时长 / 画面 / 口播 / 字幕，打印出来现场能直接用；少爷念顺、看完不超时。

## 预计顺序

1. 定钩子与卖点 —— 第一步，卖点不定，脚本白写。
2. 写口播稿 —— 串行，等钩子挑定。
3. 拆分镜 —— 串行，口播稿定了才拆镜头；参考画面生成可与写稿并行预热。
4. 成品与审片 —— 最后一步，少爷过目。
