# 任务模板：写方案或提案

## 目标示例
少爷：客户要我们出个数字化转型方案，下周五交，你先搭个架子再填肉，别让我从头写。

## 子任务拆解

### 1. 背景与目标提取
- **执行方类型**：Kimi（长文档阅读）
- **一句话验收标准**：读完客户提供的全部资料（最多 30 页），输出 500 字背景摘要和 3 条可量化目标，每条目标带"当前值 → 目标值 → 时间"结构。

### 2. 结构与要点大纲
- **执行方类型**：DeepSeek
- **一句话验收标准**：输出方案目录（现状诊断 / 痛点 / 解决方案 / 实施路径 / 报价 / 案例），每节下列 3–5 个要点，少爷能据此判断逻辑闭环。

### 3. 成文撰写
- **执行方类型**：Claude（长文写作）
- **一句话验收标准**：按大纲成文 5000–8000 字，含至少 2 处客户所在行业的数据引用，每处引用附来源 URL，无"赋能、抓手"类空词堆砌。

### 4. 校对与导出
- **执行方类型**：WPS Office（排版 + 拼写检查）
- **一句话验收标准**：导出 PDF，目录页码自动更新，WPS 拼写检查 0 错误，少爷终审签字后交付客户。

## 预计顺序
1. **背景与目标提取**（串行前置）——客户资料不读清楚后面全是臆测。
2. **结构与要点大纲**（依赖 1，串行）——大纲按提取出的目标反推。
3. **成文撰写**（依赖 2，串行）——按大纲填肉。
4. **校对与导出**（依赖 3，串行收尾）——定稿后才排版。
