# WorkBuddy 按钮与能力实测（v2 · 2026-11-06）

- **本篇适用**：要在 WorkBuddy（Windows 桌面客户端，v5.9.3）上"让 AI 真做出一件事"——尤其想知道**视频生成到底能不能出片**——时先读这篇。按钮逐字、链路步骤、费用边界、失败回退都在这里；不确定某颗按钮是什么，再回 `generic-buttons.md`。

> **与其余档案的关系**：本库原有 5 家（元宝 / 智谱 / 豆包 / WPS / 剪映）都是"聊天 + 点按钮"。WorkBuddy 是**任务式派单界面**（左栏是任务列表，不是会话列表），且视频能力**已经实测出片**——这是本库第一条"从剧本到成片全链路走通"的记录。

## §四 视频生成链（对话式，六步，已全程走通）

> 【咕嘎补注 · 2026-11-07｜执行器边界】咕嘎执行器当前未接入，勿据此承诺自动完成（图生视频 / 3D / HTML 产物：不做落盘与"可打开"校验）。

### 4.1 触发方式

**不需要找按钮**。在新任务页输入框里，把剧本、镜头、时长、比例一次说全即可。实测用句（可原样复用）：

```
用这段剧本生成一条视频：一镜到底，俯拍雨夜路面一小片积水，倒影里一块模糊的红色霓虹招牌，
第 0.3 秒一滴雨砸在水面正中、倒影碎成一圈红色光斑。时长 4 秒，比例 9:16。
```

**前置条件**：① 已登录且有可用积分；② 在 `办公` 模式的新任务页（`开发` / `设计` 模式未测）；③ 不需要事先开"技能"或选模板。

### 4.2 六步（逐字）

| 步 | 它做了什么 | 屏幕可见文字（逐字抄） |
|---|---|---|
| 1 | 认领任务，会话标题**自动改名** | 左栏标题由 `新建任务` 页变为 `生成雨夜积水倒影视频`；正文顶部出现 `WorkBuddy` + `预计消耗 ◇ 0.71 ~ 39.05`，旁边计时 `已处理 12s` |
| 2 | 声明要先确认参数 | `继续处理任务过程` / **`我来生成这条视频，先确认一下生成参数。`**，同时左栏该条出现 `待确认` 徽标 |
| 3 | 摊开费用与参数 | `这条视频的生成会额外消耗视频模型的额度（大约 50-100 credits）。参数按你的要求确定：一镜到底、俯拍、4 秒、9:16。` |
| 4 | 给镜头设计（**证明它真读了剧本**） | `核心镜头设计如下：` / `0–0.3s: 静止俯拍，雨丝斜落，积水只有巴掌大，红色霓虹招牌的倒影模糊抖动` / `0.3s: 一滴雨正好砸在水面正中，激起一小圈涟漪` / `0.3–4s: 倒影从中心碎裂，红色的光在涟漪上被拉断成环状光斑，水面持续抖动`；随后 `现在开始生成。` |
| 5 | 弹**积分确认卡**（不点它不会开工） | 卡头 `确认开始生成视频？` + 橙色 `积分消耗较高`；副行 `生成视频将消耗额外积分，每 5 秒约 50-100 积分，请谨慎操作`；三个选项：`1 确认` / `2 本次会话始终允许` / `3 拒绝` |
| 6 | 点了 `确认` 才真跑 | 确认卡消失、`待确认` 徽标消失；出现 `视频生成中  一镜到底，无剪辑，垂直俯拍（90度正上方俯视）雨夜柏油路面上的一小片积水，积水只占画面下半部分，…`；`生成视频，预计需要 3-10 分钟`；缩略卡上 `生成中 1%`；计数 `已消耗 ◇ 0.83` |

### 4.3 完成判据（唯一判据）

**必须出现下面三样，缺一不算完成**：

1. 顶部状态变成 **`已完成 3m15s`**（`3m15s` 是本次实耗，不是固定值）；
2. 正文出现 **`视频生成好了，已经放在预览里。`** 与 **`文件： <文件名>.mp4（1.2 MB, MP4）`**；
3. 右侧预览面板出现 **播放条 `0:00 / 0:04`**（`/0:04` 即真实时长），画面左上角带 `AI生成` 角标。

**只到"参数确认卡"不算成功；只到"生成中 1%"不算成功；拿到 .mp4 文件且能在预览里播放，才算成功。**

### 4.4 完成后它还会交代什么（原文，可直接抄进汇报）

- `我给你的脚本做了这些具体处理：` 六条：明确写了"镜头完全静止、无镜头运动"（确保一镜到底不变运镜）；写明"第 0.3 秒"作为动作发生的时机；补充了涟漪切断倒影、把倒影拉成长条再散成环形光斑的形态变化（避免 AI 只做"水面波动"这种笼统处理）；加了"路灯冷白光在积水边缘形成细亮高光边"和"雨丝拖影"；特意排除了人物和文字（防止模型自动加上路人和招牌上的字）。
- `可能需要调整的地方：AI 对"精确 0.3 秒"这种时间点控制不会非常准，雨滴可能提前或延后几十毫秒；另外 4 秒时长如果模型的实际输出有偏差，建议拿到素材后在剪辑软件里重新截取定版。`
- `想再生成几个版本挑选，或者换成"雨滴更大、溅起水花"以及"霓虹由绿变红"这类不同变化，告诉我就行。`
- 操作行：点赞 / 踩 / 复制 / 重试 / 分享 / `…`；右端 `共消耗 ◇ 58.69` 与 `快速（DeepSeek-V4.1-Flash）`；产物区 `查看所有产物 (1) >`。

### 4.5 第二种走法：`设计` 档 + `视频生成` chip（10 秒 / 16:9，已出片）

与 4.1~4.4 的差别**只在入口与确认形态**，完成判据完全一致（拿到可播放 mp4 且时长真实）。

## §六 技能与工具体系（写文档、做表、出图都走这里）

- 技能位 **46 个**（builtin 24 + userSettings 21 + plugin 1），可用 `<用户目录>\.workbuddy\.skill-list-cache.json` 读全量清单。**口径别写错**：`技能` 页点 `已安装` 显示 `还没有安装任何技能`——46 个全是内置/设置位，**用户自己没装第三方技能**。
