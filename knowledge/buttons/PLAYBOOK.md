# KB8 · 任务剧本 PLAYBOOK（真机实测沉淀 · 2026-11-06）

> **本文件是什么**：把"用户一句话要办成的事"翻译成"按哪几颗按钮、按什么顺序点、点对了看什么"。四条链全部来自本库已实测条目，**没有一条是推演出来的**。
> **本文件不是什么**：不是教程、不是最佳实践。每条链最后一步如果本库没实测过，就原样写"本库未实测，停止并报人工"，**不许补写**。
> **三条读法**：① 先看 `- **前置条件**`，条件不满足直接停；② `- **步骤**` 里的锚文本是**逐字**判据，看到不同字样就说明点偏了；③ `- **依据**` 指回原档案编号，要细节去原文看。

## 任务：用豆包写一篇作文

- **触发**：用户说"帮我写一篇作文/帮我写一段文章"，希望用豆包生成正文
- **前置条件**：
  - 豆包桌面版已登录（本库 12 颗实测均在已登录态）；版本 147.0.7727.149
  - 100% 缩放 / 2560×1600 单屏；窗口最大化 2560×1528
  - 当前停在**对话态**（占位 `有什么我能帮你的吗？`），不是工作态
- **步骤**：
  1. 点侧栏 `新对话` → 完成判据：输入区占位变 `有什么我能帮你的吗？`，该项选中后显示快捷键 `Ctrl Shift K`
  2. 若占位是 `今天有什么工作要处理？`（工作态，侧栏收窄），点首页 `对话` 分段切回 → 完成判据：占位回到 `有什么我能帮你的吗？`
  3. 需要给范文或素材时：点输入区 `+` → 菜单第一项 `上传文件或图片` → 系统「打开」框（**无类型下拉**，起始用户主目录）→ 完成判据：输入区出现附件卡
  4. 在输入区写提示词
  5. **点发送：本库未实测，停止并报人工**（发送会真实产生对话并消耗额度，本库只读不点）
- **完成判据**：屏幕上出现回答气泡。**本库未实测**（发送未点过，无法给出可核对的锚文本）
- **失败回退**：`+` 浮层 **Esc 关不掉** → 点会话正文空白处关掉（E-020）；窗口标题随会话变（有会话是「会话名 - 豆包」，点 `新工作任务` 后变成纯 `豆包`）→ 按标题找窗口的脚本必须重取（E-021）
- **边界**：不要动 `按需确认` 三档里的 `全部允许`（会改变执行器授权行为）；不要动 `本地电脑 ▸` 里的 `云电脑`（会把执行位置切出本机）；不要点 `共享屏幕和应用`（会遮盖界面）
- **依据**：`doubao-buttons.md` D01 / D02 / D09 / D11；`experience.md` E-020 / E-021

## 任务：用 WPS 把文档导出成 PDF

- **触发**：用户说"把这个文档导出成 PDF"，且文档已在 WPS 里打开
- **前置条件**：
  - WPS Office 12.2.0.23196，**界面英文**（锚文本按英文原文）
  - 已有一个打开的文档，标题形如 `Document1 - WPS Office`
  - 100% 缩放（AppliedDPI=96）/ 2560×1600 单屏
- **步骤**：
  1. 点功能区 `≡ File` → 完成判据：左侧滑出整块浮层，出现 `New` / `Open` / `Save` / `Save As` / `Export to PDF` / `Export to Picture` / `Print` / `Share` 等项
  2. 点 `Export to PDF` → 完成判据：**主窗内嵌浮层**（无新窗口），出现 `Select all (1)` / `Export range` / `Same directory as source file` / `Common PDF` / `Image PDF` / `Backup to Cloud` / `Open after export`（默认已勾）
  3. 核对导出范围与格式选项
  4. **点浮层里的最终 `Export`：本库未实测，停止并报人工**（写盘动作，需用户在场）
- **完成判据**：源文件同目录出现同名 PDF。**本库未实测**（最终 `Export` 未点过，无法给出文件判据）
- **失败回退**：若落到的其实是 `Save As` 保存框（输入框 `File Name` 预填正文首句，如 `This sentence is very bad written.docx`），说明点到了 `Share ⌄`（W12），不是导出面板——**本库只登记了"会落到保存框"这个事实，取消路径未实测，报人工**
- **边界**：`Print` / `Save` / `Save As` 会写盘或占打印机，只读不点；`Export to Picture` 会弹**独立窗口** 1317×859（含 `Export Type` / `Watermark` / `Pages All` / `Format PNG` / `Quality Standard (200%)` / `Export`），与本链无关，别混
- **依据**：`wps-buttons.md` W07 / W10 / W11 / W12

## 任务：用元宝上传本地文件

- **触发**：用户说"把这个文件发给元宝看看"，需要把本地文件作为附件喂进对话
- **前置条件**：
  - 腾讯元宝 2.91.0.607，已登录
  - 100% 缩放 / 2560×1600 单屏；元宝窗口 1804×982
  - 要传的文件在本地可访问，且是 office 系（框内类型白名单为 office 系）
- **步骤**：
  1. 点输入区 `+` → 完成判据：向上弹五项菜单，逐字为 `联网搜索` / `上传图片` / `本地文件` / `腾讯文档` / `截图提问`
  2. 点 `本地文件` → 完成判据：呼出系统「打开」框；选中文件后输入区出现附件卡，卡上形如 `PPTX ｜ 11.78M`
  3. 在输入区写提示词
  4. **点发送：本库未实测，停止并报人工**（会真实产生对话并消耗额度）
- **完成判据**：输入区出现附件卡（这一步本库已实测）；文件被模型读到的判据 **本库未实测**
- **失败回退**：菜单里 `腾讯文档` 是**另一条路**——点它会弹 `腾讯文档账号授权` 框（6 条权限 + `同意`），协议行默认未勾、直接点同意像没反应，需用户在场；`上传图片` 走的是同一类系统「打开」框但起始目录是桌面
- **边界**：不点 `腾讯文档`（涉账号授权）；不点 `截图提问`（会遮盖界面）；`+` 浮层的 Esc 关闭行为本库未登记，关不掉就报人工
- **依据**：`yuanbao-buttons.md` Y11 / Y12 / Y13 / Y14

## 任务：用剪映导出一段视频

- **触发**：用户说"把这段视频导出成文件"，时间线上已有片段
- **前置条件**：
  - 剪映专业版 11.7.0.14652，**已登录**（首页左栏顶部有 `个人版` + `抖音主页>`；出现 `点击登录` = 未登录，**立刻报人工，不许点 `×`**，那会让整个进程退出）
  - 编辑器已打开，时间线**非空**
  - 100% 缩放 / 2560×1600；编辑器最大化矩形 0|0|2560|1528
- **步骤**：
  1. 启动后先过环境检测 → 完成判据：出现 `环境检测中...` 后转成 `您的电脑可以流畅使用剪映` + `确定`
  2. 会员导流弹窗点 `放弃福利` → 完成判据：弹窗消失，标题变 `剪映专业版`，出现 `开始创作`
  3. 点首页 `开始创作` → 完成判据：**新开编辑器窗口**（不替换当前窗），标题变 `JianyingPro`，右侧有 `导出`
  4. 编辑器首次引导浮层点 `退出教程` → 完成判据：`1/5` 浮层消失，露出 `菜单 ⌄` / `自动保存本地` / `分享` / `导出`
  5. 点右上 `导出` → 完成判据之一：时间线为空时被拦，弹 `无法导出，时间线为空` + `知道了`（**此时不重试**）；时间线有片段时打开导出设置面板，出现 `导出时间线`=`时间线01`、`分辨率`=`原始`、`格式`=`MP4`、`帧率`=`30`、`时长: 5 秒 | 大小: 2 MB（估计）`
  6. **点面板底部 `导出`：本库未实测，停止并报人工**（写盘动作，需用户在场）
- **完成判据**：磁盘上出现导出的 MP4。**本库未实测**（最终 `导出` 按钮从未按过；草稿 `draft_content.json` 是加密串，也不能靠读文件验证）
- **失败回退**：窗口标题在首页/编辑器之间会变（`剪映专业版` ↔ `JianyingPro`），hwnd 每次启动都变，按标题找窗口会找错 → 按矩形/尺寸判（E-048）；**不要二次 `Start-Process`**，会崩 `unknown software exception (0x80000003)`（E-049），只能全杀进程单次重启；播放器 `全屏` 一旦进入 `Esc` 与收起图标都退不出，只能杀进程
- **边界**：时间线工具栏垃圾桶 / `删除` 只读不点；`全屏` 属不可回退风险项；同一时间线为空时不要重复点 `导出` 试探
- **依据**：`jianying-buttons.md` J05 / J06 / J07 / J12 / 补证 J12；`experience.md` E-048 / E-049 / E-059
