## 适用条件

- **适用版本**：剪映专业版 **11.7.0.14652**（主程序 `C:\Users\<user>\AppData\Local\JianyingPro\Apps\11.7.0.14652\JianyingPro.exe`）
- **登录态**：**分两种**。未登录：登录层无「跳过」，点 `×` 即整个进程退出（E-023），不可自动化；已登录：首页左栏顶部出现 `个人版` + `抖音主页>`，走 `放弃福利` → `首页` → `开始创作` → 编辑器
- **缩放与分辨率**：Windows 11 单屏 **2560×1600**、缩放 **100%**；编辑器最大化矩形 0|0|2560|1528。150% / 其他分辨率**未测**
- **失效条件**：窗口标题分工不稳（首页 `剪映专业版` ↔ 编辑器 `JianyingPro`，E-048），hwnd 每次启动都变，必须按矩形/尺寸判窗；草稿 `draft_content.json` 是加密串（E-059），不能靠读文件验证编辑结果（**推断**：版本升级后页签行与时间线工具栏项序可能变化）
- **风险**：播放器 `全屏` 一旦进入，`Esc` 与收起图标都退不出来，只能杀进程重启；登录层点 `×` 会直接退出程序；`删除` / `导出` / `发布` 属破坏性或写盘动作，本库只读不点；重复 `Start-Process` 二次启动必崩 `0x80000003`（E-049）

## ⛔→✅ 结论（改判）：**能不能自动化，取决于登录态，不是软件本身**

- **本篇适用**：用户问剪映到底能不能自动点、什么登录条件下才可以

**旧结论「对 agent 不可自动化」已作废**（作废原因：它只对"未登录"那台机器状态成立，第六轮实测本机**已登录**，一路进到编辑器）。新结论：

| 状态 | 事实 | 处置 |
|---|---|---|
| **未登录** | 登录层**无"跳过"旁路**；点 `×` 会让**整个进程退出**（E-023 实测） | **报人工**，不重试、不点 `×` |
| **已登录** | 启动 → 会员导流弹窗 `放弃福利` → 首页（左栏顶部 `个人版` + `抖音主页>`）→ `开始创作` → **编辑器正常打开** | **可自动化**，按本档案已实测条目操作 |

> **执行器纪律**：先看首页左栏顶部——有 `个人版`/头像 = 已登录可继续；出现 `点击登录` = 未登录，立刻按上表"报人工"。
> **不要沿用旧结论**：写"剪映不可自动化"的人用的是未登录那台机器的证据，本库已改判。

**已实测范围（共 27 颗）**：启动 4 步 + 会员弹窗 `放弃福利` + 首页 `开始创作` + 首次引导 `退出教程`；第七轮补齐编辑器内部 5 颗——`菜单 ⌄`、页签 `音频`、音频页 `导入 ⌄`、`分享`、`导出`（C2 节）；**第八轮在"有片段"前提下再补 3 颗**——素材页大卡 `导入`、素材页 `导入 ⌄`、时间线 `分割`，并把 `分享`/`导出` 补证到"有片段时"（C3 节）。编辑器其余按钮仍标"未点"（见 D 节）；**第九轮再补 2 颗**——时间线缩放 `−`/`+`、播放器 `全屏`（C4 节，含"退出失败"的如实记录）。

### J05 启动后会员导流弹窗 `放弃福利`

- **按钮原文**：`放弃福利`（画面右下，灰底；右侧并排一颗粉底 `立即购买`）
- **图标特征**：纯文字按钮，无图标；弹窗上半是「剪映X即梦联合会员」大图，下半 `剪映X即梦联合会员` + `让AI助力视频创作，限时优惠3折起`
- **位置参照**：弹窗**底部右侧**两颗并排，左灰 `放弃福利`、右粉 `立即购买`
- **点击后果**：**关闭弹窗并进入首页**；窗口标题由 `JianyingPro` 变为 **`剪映专业版`**
- **结果锚文本（逐字）**：首页左栏 `新人福利，幸运2折`、`首页`、`模板`、`我的云空间`、`小组云空间`、`即梦AI`、`即梦短剧`；主区大按钮 **`开始创作`**
- **如何确认点对**：标题变 `剪映专业版` 且主区出现 `开始创作`（若误点右侧则进购买页）
- **易混按钮**：`立即购买` 就在右侧**同一高度**，颜色更亮（粉色）——**不要点**
- **误点后果与恢复**：点 `放弃福利` 只关导流，不产生任何订阅；点 `立即购买` 会进支付流程（**本库未测，也不要测**）
- **对话可用性**：与对话无关（纯导流），agent 应无条件点 `放弃福利`
- **证据**：`imgs/jianying-btn_promo_popup-1.png`

### J06 首页 `开始创作`

- **按钮原文**：`开始创作`（左侧一枚圆形 `+` 图标，整条是横贯主区的大卡片）
- **图标特征**：深色横向大卡片 + 白色圆形加号 + 白字，卡片底色是蓝紫渐变
- **位置参照**：首页主区**最上方一张大卡**，其下是 `剪映Hub`/`AI文字成片`/`图片设计`/`营销成片`/`AI切片`/`视频翻译` 一排能力卡

- **结果锚文本（逐字）**：窗口标题 `JianyingPro`；编辑器标题栏中部显示草稿名 **`11月6日`**；右栏标题 `草稿参数`，其下 `草稿名称:` `11月6日`、`保存位置:` `C:\Users\<user>\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft\11月6日`
- **如何确认点对**：窗口列表里**多出一个 `JianyingPro` 窗口**，且编辑器顶部出现草稿名与 `导出`
- **易混按钮**：下方 `剪映Hub` 也是大卡但是"功能页"入口，不是新建草稿；左栏 `首页` 是导航不是新建
- **误点后果与恢复**：只是新建空草稿（不覆盖旧草稿）；关掉该窗口即回首页
- **对话可用性**：与视频类任务强相关（这是剪映里唯一的"开工"入口）
- **证据**：`imgs/jianying-home_loggedin-1.png`（首页全貌）

### J07 编辑器首次引导浮层 `退出教程`

## C2. 第七轮新增实测：编辑器内部 5 颗（已登录态，2026-11-06）

- **本篇适用**：用户问剪映编辑器菜单、音频页签、音频导入、空时间线分享和导出会怎样

> 前置：编辑器窗口已打开、草稿为空的 `11月6日 (1)`。**空时间线**这个前提对下面几条后果有决定性影响（`分享`/`导出` 都是被空时间线拦住的）。

### J08 编辑器左上 `菜单 ⌄`

- **按钮原文**：`菜单`（右侧一枚下箭头 `⌄`，点开后箭头变 `⌃`）
- **图标特征**：纯文字 + 箭头，深色圆角块，紧挨左侧 `剪映` logo
- **位置参照**：编辑器**标题栏最左**，`剪映` logo 右侧第一颗
- **点击后果**：**就地下拉出竖向菜单**（不是新窗口、不是侧栏）
- **结果锚文本（逐字）**：`文件 ›`、`编辑 ›`、`布局模式 ›`、`更多操作 ›`、`帮助 ›`、`账号 ›`、`全局设置`、`返回首页`、`退出剪映`；其中 `文件` 展开的二级项为 `新建草稿`、`新建`、`导入`、`导出`
- **如何确认点对**：`菜单` 右侧箭头由 `⌄` 变 `⌃`，且下方出现 `文件 ›` 起头的竖列
- **易混按钮**：左端 `剪映` logo 紧邻其左（点 logo 无菜单）；`文件` 里的 `导出` 与右上角青底 `导出` 是**两个入口**（右上那颗才是主入口）
- **误点后果与恢复**：`退出剪映` /`返回首页` 会离开当前草稿（草稿自动保存在本地，已实测标题栏有 `自动保存本地` 时间戳）；**菜单本身可用 `Esc` 关掉**（本轮实测 Esc 一次即收起）
- **对话可用性**：agent 找"新建草稿/导入/导出"的**最短路径就在这里**，不必去首页
- **证据**：`imgs/jianying-btn_menu-1.png`（一级菜单展开）、`imgs/jianying-btn_menu_file-1.png`（`文件` 二级展开）

### J09 页签 `音频`

- **按钮原文**：`音频`（上方一枚唱片/音符线描图标）
- **图标特征**：线描圆盘图标 + 两字标签，未选中是灰蓝、选中变青色
- **位置参照**：素材面板**页签行第 2 颗**（左起 `素材` 之后）
- **点击后果**：**只换左侧素材面板内容**，播放器/时间线/右栏 `草稿参数` 全部不动
- **结果锚文本（逐字）**：左列变 `导入 ⌄`、`我的 ⌄`、`AI 音乐`、`音乐库 ⌄`（展开后 `会员热榜`/`推荐音乐`/`最新`/`日出出逃`/`团圆时刻`/`慵懒BGM`/`纯音乐`/`旅行`/`轻快`/`K-POP热单`）；搜索框占位 `搜索歌曲名称/歌手`；右侧标题 `会员热榜`，曲目卡带 `02:37`、`01:12` 这类时长与三星标/下载标
- **如何确认点对**：`音频` 标签变青色，且搜索框占位从 `搜索文件名` 变为 `搜索歌曲名称/歌手`
- **易混按钮**：`音乐库` 是页签**内部**的分组，不是页签；`素材` 页也有 `导入`，但两者展开内容不同
- **误点后果与恢复**：纯浏览，不下载不扣费；点回 `素材` 即还原
- **对话可用性**：做"配乐/加 BGM"类任务时，必须先切到这里再谈选曲
- **证据**：`imgs/jianying-tab_audio-1.png`

### J10 音频页左列 `导入 ⌄`

- **按钮原文**：`导入`（右侧 `⌄`；展开后左侧竖条变青色高亮）
- **图标特征**：纯文字 + 下箭头，展开后下方直接出现卡片区
- **位置参照**：音频页**左列最上方第一颗**（`我的 ⌄` 之上）
- **点击后果**：**就地展开自绘子面板**（**不弹系统文件对话框**），出现两张功能卡
- **结果锚文本（逐字）**：`音频提取` + `支持视频文件提取音频` + 按钮 `导入`；`链接下载` + `粘贴抖音分享的视频/音乐链接` + 按钮 `粘贴链接`
- **如何确认点对**：`导入` 行左侧变青色，右侧出现 `音频提取`/`链接下载` 两张卡
- **易混按钮**：卡片内的 `导入`（小按钮）才是真开文件框的那颗；`导入 ⌄` 只是展开分组。素材页的 `导入 ⌄` **本轮未点**（不拿这一条当素材页结论）
- **误点后果与恢复**：只展开面板，不产生任何文件操作；再点一次即收起
- **对话可用性**：agent 想"提取某视频的音频"就走 `音频提取 → 导入`；想"从抖音链接拿素材"走 `粘贴链接`（**会联网拉取，未实测**）
- **证据**：`imgs/jianying-btn_import_panel-1.png`

### J11 右上 `分享`

- **按钮原文**：`分享`（左侧一枚"向外箭头 + 方框"线描图标）
- **图标特征**：深灰胶囊 + 白色线描图标 + 白字，紧邻右侧青底 `导出`
- **位置参照**：编辑器标题栏**最右侧功能区**，`导出` 左边一颗
- **点击后果**：**空时间线时被前置拦截**——弹出小提示窗（288×315），**不打开任何分享/审阅流程**
- **结果锚文本（逐字）**：标题 `无法审阅，时间线为空`；正文 `时间线上没有片段时将无法审阅，请添加一些片段后再尝试。`；按钮 `知道了`
- **如何确认点对**：出现上述小窗，且**没有**弹出账号绑定/发布渠道列表
- **易混按钮**：与右上青底 `导出` 只差 100 px 左右，颜色不同（分享是深灰、导出是亮青）
- **误点后果与恢复**：点 `知道了` 即关，无副作用；**有片段时的分享面板仍未测**（不能拿这条说"分享就是弹错误框"）
- **对话可用性**：这是"协作审阅"入口，不是发布；空草稿下 agent 点了只会拿到这条拦截文案
- **证据**：`imgs/jianying-btn_share_empty-1.png`

### J12 右上 `导出`

- **按钮原文**：`导出`（左侧一枚"向上箭头 + 托盘"线描图标）
- **图标特征**：**亮青色实底**胶囊 + 白图标白字，是标题栏最显眼的一颗
- **位置参照**：编辑器标题栏**最右侧**，`分享` 右边一颗、窗口控制按钮左边
- **点击后果**：**空时间线时被前置拦截**——弹小提示窗，**没有进入导出设置、没有写任何文件**
- **结果锚文本（逐字）**：标题 `无法导出，时间线为空`；正文 `时间线上没有片段时将无法导出，请添加一些片段后再尝试。`；按钮 `知道了`
- **如何确认点对**：出现上述小窗；若出现"导出设置/分辨率/码率"面板说明有片段，属另一情形
- **易混按钮**：`菜单 → 文件 → 导出` 是同功能的第二个入口（**该入口未点**）
- **误点后果与恢复**：点 `知道了` 关闭即可；**有片段时的真导出（会写 mp4 到磁盘）仍未测**，须用户在场再操作

### C6 附带确认的四条界面事实

1. **`基础编辑 ›` 五项在视频片段上全部可用**（`定格`/`倒放`/`镜像`/`旋转`/`裁剪` 均非灰）；在图片片段上 `定格`/`倒放` 为灰。**这就是上一轮"灰"的全部原因**。

3. **一个草稿可挂多条时间线**：素材右键 `根据选中素材新建时间线` 后，时间线页签行由一条变两条——`时间线01` / `时间线02`，播放器标题同步变成 `播放器-时间线02`；两条时间线各自保存片段，互不影响。
4. **素材拖上时间线不是每次都能成**：本轮在同一台机器、同一窗口状态下按真实鼠标拖拽试了三次（落点分别是空白轨上方、属性面板边缘、轨道行内），**都没有生成新片段**；改走素材右键 `根据选中素材新建时间线` 一次成功。故"拖拽可行"只能作为**曾经成功过**的记录，不能当成稳定路径。

## F. 测试方案（照此执行，避免弄坏用户素材）

- **本篇适用**：用户问测剪映时怎么避免弄坏素材和草稿

1. **不碰用户工程**：只用新建的空草稿（`11月6日` 这类默认名）。
2. **一条素材原则**：只导 1 条 10 秒内短视频/1 张图，**绝不导入用户真实项目素材**。
3. **破坏性按钮只读不点**：`删除`、`导出`、`分享发布`、`清空`类只记位置；必须点时须用户在场。
4. **每颗三步取证**：①点前截帧；②点后 1.4 秒内截帧；③弹面板再截全貌。
5. **失败判据**：连点两次无变化 → 判"落点偏"，不连点第三次（E-009）。
6. **回填**：九字段当场写，不靠回忆。
7. **⚠ 本轮新坑**：同一时刻会出现**多个标题为 `JianyingPro` 的窗口**（编辑器 + 浮层 + 助手），`winsnap` 按标题只取到"第一个"——**改用 `-title '__all__'` 按 hwnd 认窗，或整屏截图再裁剪**（本轮即因这条先截到浮层，白折腾一次）。
