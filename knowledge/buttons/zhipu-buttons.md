# 智谱清言 · 按钮功能地图（KB8-3）

- **档案ID**：zhipu-buttons
- **软件**：智谱清言 Windows 桌面客户端 2.0.7
- **实测日期**：2026-11-06（Asia/Shanghai），本机已登录
- **验证环境**：Windows 11 / 单屏 2560×1600 / 缩放 100% / 智谱窗口 1903×1282（**单环境验证**；150% 与其他分辨率未测）
- **取证方式**：真实鼠标点击（系统级真实坐标注入）+ 点后立即窗口级截帧核对

> **执行器最容易踩的一条**：智谱有个 **「对话 / 任务」分段开关**，同一个输入区会变成**两套完全不同的界面**（占位文字、模型、模板、`选择分组` 行都会变）。只记住"输入框长什么样"不够，必须记住当前在哪个模式。
> 另一条：侧栏第一项的**文字会变**——任务模式叫 `新建任务`，对话模式叫 `新对话`，**是同一个按钮**。

## 适用条件

- **适用版本**：智谱清言 Windows 桌面客户端 **2.0.7**（本机实测版本；版本号取自本档案元信息）
- **登录态**：**已登录**。本档案全部 16 颗实测均在本机已登录态下完成；未登录态本库未实测
- **缩放与分辨率**：Windows 11 单屏 **2560×1600**、缩放 **100%**、智谱窗口 1903×1282。150% / 125% 与其他分辨率**未测**
- **失效条件**：`对话 / 任务` 分段切换后同一位置的按钮文字与功能都会变，按旧截图定位会点偏；软件升级后模板卡与工具箱项数可能变化（**推断**）

- **按钮原文**：任务模式显示 `新建任务`；对话模式显示 `新对话`（**同一位置、同一功能，文字随模式变**）

## 二、输入区（**两套界面，务必按模式分别对待**）

- **本篇适用**：用户问智谱清言对话模式和任务模式输入区有什么不同、加号能上传什么

### 「对话 / 任务」分段开关 ⭐ 最容易误判

- **按钮原文**：`对话` / `任务`（同一颗胶囊里的两段）
- **图标特征**：胶囊形分段控件，当前项填充深色并带亮蓝文字
- **位置参照**：输入卡片**左下角**，`+` 圆钮**右侧**；再往右是模型下拉、麦克风、发送
- **点击后果**：**切换整个输入区的模式**（不是发送方式、不切页）。任务模式=复杂任务工作台；对话模式=普通聊天
- **结果锚文本**：
  - 切到 **`对话`**：占位 `和我聊聊天吧~`；模型自动变 `GLM-5.3-Flash 极致`；`选择分组` 行**消失**；下方模板换成 `随机穿越历史猜人物` / `脱口秀式冷知识` / `沉浸式角色扮演` / `python技术实现`；侧栏第 1 项文字变 `新对话`；主区欢迎语变 `要求尽管提，我不糊弄更不烧心 😜`
  - 切到 **`任务`**：占位 `处理复杂工作`；模型 `GLM-5.3 极致`；出现 `选择分组` 行；下方模板 `PPT制作` / `研究报告` / `数据分析` / `网站制作`；侧栏第 1 项文字变 `新建任务`
- **如何确认点对了**：**看占位文字**（`处理复杂工作` vs `和我聊聊天吧~`）最稳，其次看模型名是否带 `-Flash`
- **易混按钮**：**没有**易混项，但它会**连带改变周边 4 处显示**（模型名、`选择分组` 行、模板行、侧栏首项文字），若只盯其中一处变化会误判"没生效"
- **误点后果与恢复**：切错模式后直接对话仍可用（对话模式也能干活，只是没有任务模板/分组），**再点回去即可**，无数据损失
- **对话可用性**：✅ 两种模式都能对话
- **实测状态**：【实测】2026-11-06，`imgs/zhipu-btn_mode_chat-1.png`（对话模式全貌）

### 「+」（输入卡片左下角加号）

- **按钮原文**：无文字，`+`
- **图标特征**：圆角方形浅灰底、内一个加号（与元宝的实心圆 ⊕ 不同）
- **位置参照**：输入卡片**最左下角**；右邻 `对话/任务` 分段
- **点击后果**：**在按钮左上方弹出两项浮层**，浮层向左溢出到窗口边缘外侧仍可点
- **结果锚文本**：`上传文件或图片` / `联网搜索 ▸`
- **如何确认点对了**：出现两项竖排浮层，`联网搜索` 行尾带右尖括号 `>`
- **易混按钮**：无（智谱输入区只有这一颗 `+`）
- **误点后果与恢复**：只弹浮层，点空白或再点 `+` 关闭；**注意 Esc 对浮层也不稳，优先再点一次 `+`**
- **对话可用性**：✅
- **实测状态**：【实测】2026-11-06，`imgs/zhipu-btn_plus-1.png`
  - **重要更正**：上一轮记录"智谱 + 浮层弹不出（3 次失败）"。本轮实测**能弹**，失败原因是①当时在任务模式②落点 y 偏了（点到了分段控件上方）。**判据：`+` 的命中点在输入卡片底边上方约 20px，别按输入框中心算**

### 「上传文件或图片」（`+` 浮层第 1 项）

- **按钮原文**：`上传文件或图片`
- **图标特征**：向上箭头 + 托盘（上传图标）
- **位置参照**：`+` **左上方浮层第一行**
- **点击后果**：**呼出系统「打开」文件对话框**（标准 Windows 打开框，标题 `打开`）
- **结果锚文本**：对话框左上标题 `打开`；底部 `文件名(N):` 与类型框 **`所有文件 (*.*)`**；右下按钮 `打开(O)` / `取消`
- **如何确认点对了**：出现系统级「打开」框（不是应用内选文件面板）；**类型框显示 `所有文件 (*.*)`**——说明**智谱不设格式白名单**（与元宝不同：元宝只列 office/pdf 等受限格式）
- **易混按钮**：无（浮层只有两项）
- **误点后果与恢复**：只开系统框，按 `取消` 或 Esc 关闭即回原状，不会上传任何东西
- **对话可用性**：✅（框关掉即可继续）
- **实测状态**：【实测】2026-11-06，`imgs/zhipu-btn_filebox-1.png`
  - **补充实测事实**：对话框打开位置停在上次访问的 `此电脑 > Windows-SSD (C:) > Windows > System32`，不是用户目录——执行器找文件**不要指望默认目录**，直接用路径栏输路径
