# 通用按钮档案（KB8-4 · generic）

- **档案ID**：generic-buttons
- **定位**：**兜底档案**。适用于两类对象：
  1. 名单内但**本机未装/本轮未能实测**的软件；
  2. 名单外的新增 AI 客户端（用户临时让咕嘎去操作的任意 AI 桌面软件）。
- **本档案的性质**：**不含任何软件的逐按钮实测结论**，只给"按钮族识别法则 + 安全操作顺序 + 判错兜底"。**任何一条都不能当成某软件已实测的结论引用。**
- **证据来源**：本条目的判据来自本库已在真机实测过的三个软件（元宝 / 智谱 / 豆包，见 `yuanbao-buttons.md`、`zhipu-buttons.md`、`doubao-buttons.md`）中被反复验证的规律，**属"跨软件归纳"，不是新软件上的实测**。
- **实测日期**：归纳于 2026-11-06。

---

## 一、通用按钮族（按"后果类型"分类，不按文字）

- **本篇适用**：用户问各类软件里同名按钮（关闭、取消、确定、跳过）点了分别什么后果

AI 客户端的按钮，无论长什么样，按后果只有六族。识别出族别，再决定敢不敢点。

### 第 1 族 · 会话入口族（安全，随便点）

- **按钮原文（三家实测出现过的形态）**：`新建对话` / `新对话` / `新建任务` / `新工作任务` / `+新建`（形态各软件不同，**文字不可靠**）
- **图标特征**：圆形加号 ⊕、气泡、对话气泡带小笔
- **位置参照**：**左侧栏最上方第一或第二行**；或输入框左下第一颗圆钮
- **点击后果**：开一个新会话/空任务页，不切功能页
- **结果锚文本**：输入框占位文字（`发送消息` / `聊点什么` / `和我聊聊天吧~` / `处理复杂工作` 一类）；主区出现欢迎语或任务台标题
- **如何确认点对**：**主区/输入区出现可输入的空框**，且侧栏该行高亮
- **易混按钮**：同区域里的 `AI创作` / `AI生图` / `图片创作` / `写作` / `PPT生成`（**这些是"功能入口"，不是会话入口**）
- **误点后果与恢复**：误进功能页后，**回来点会话入口族按钮**即可；三家实测均有效
- **对话可用性**：✅
- **实测归属**：元宝/智谱/豆包均已实测（见各自档案）；**其他软件未实测**

### 第 2 族 · 功能页入口族（危险，会把对话切走）

- **按钮原文**：`AI创作` / `AI生图` / `图片创作` / `AI画图` / `AI生视频` / `写作` / `解题` / `深度研究` / `PPT生成` / `Skills 技能` / `技能` / `工具箱` / `插件` / `智能体中心`
- **图标特征**：笔+画板、调色盘、方框P、灯泡+齿轮、四格方块、望远镜
- **位置参照**：**左侧栏（会话入口族的下方）**，或**输入行右侧一串文字按钮**
- **点击后果**：切到生图页 / 技能市场页 / 工具清单，**原会话上下文可能被切走**
- **结果锚文本（逐字，已实测）**：
  - 元宝：`开始你的创作吧`
  - 智谱：`Skills` + `找对技能，搞定任务`；或弹出 `AI生视频/画图/学习搭子/智能体中心` 四行菜单
  - 豆包：弹出 10 项长菜单（含 `上传文件或图片`）
- **如何确认点对**：**主区标题换了，或者弹出了一串横向/纵向清单**
- **易混按钮**：第 1 族（会话入口）——**这是本库记录的最大事故源（元宝彩排事故）**
- **误点后果与恢复**：对话不可用；**恢复=点第 1 族按钮**。若点了会开模态的项（如智谱 `创建项目`），模态右上角 × 关闭，**不要依赖 Esc**
- **对话可用性**：❌ 页内不能对话（技能卡「使用」可回聊天页并预填，元宝已实测）
- **实测归属**：元宝/智谱/豆包均已实测其中若干项；**其余未实测**

### 第 3 族 · 输入区「+」族（安全，但是三家的内容完全不同）

- **按钮原文**：无文字，`+`
- **图标特征**：圆角方框内加号 / 实心圆内加号 / 纯细线加号
- **位置参照**：**输入框左下角**（不是侧栏）
- **点击后果**：弹出一个"插入型"浮层（文件/图片/联网/截图/结构块）
- **结果锚文本（三家实测原文）**：
  - 元宝五项：`联网搜索` / `上传图片` / `本地文件` / `腾讯文档` / `截图提问`
  - 智谱两项：`上传文件或图片` / `联网搜索 ▸`
  - 豆包十项：`上传文件或图片` / `添加文件夹` / `选择云盘文件` / `共享屏幕和应用` / `截图提问` / `技能` / `插件` / `目标` / `计划` / `设计资产`
- **如何确认点对**：出现 2～10 项竖排/上推浮层
- **易混按钮**：第 4 族「工作模式切换」（豆包 `本地电脑 ›`、智谱 `对话/任务`、元宝 `快速回答 ⌄`）——**位置相邻、也都弹菜单**
- **误点后果与恢复**：只弹浮层；**关闭方式：点空白，不要按 Esc**（元宝可 Esc，智谱/豆包实测 Esc 无效）
- **对话可用性**：✅
- **实测归属**：三家均已实测；**其他软件未实测**

### 第 4 族 · 模式/模型切换族（安全，但会改行为）

- **按钮原文**：`快速回答 ⌄` / `深度思考` / `专家模式` / `对话` / `任务` / `本地电脑 ›` / `云电脑` / `GLM-5.3 极致 ⌄` / `自动 低 ›` / `按需确认 ›`
- **图标特征**：闪电、胶囊分段、显示器、下箭头
- **位置参照**：**输入行中部或右侧**（`+` 的右边）
- **点击后果**：切换回答模式/模型/执行环境/授权策略，**不切页、不发送**
- **结果锚文本（已实测）**：
  - 元宝：`模型 ▸ Hy3` / `快速回答 ✓` / `深度思考` / `专家模式`
  - 智谱：`处理复杂工作` ↔ `和我聊聊天吧~`（占位文字翻转）；`GLM-5.3` / `GLM-5.3-Flash` / `思考强度 极致 >`
  - 豆包：`对话` / `工作任务 ● 本地电脑 ✓` / `工作任务 ● 云电脑`
- **如何确认点对**：菜单里出现"模式/模型/环境"字样，**且输入框占位文字或模型名随之变化**
- **易混按钮**：第 3 族「+」；第 2 族的同类功能按钮
- **误点后果与恢复**：改了就改回来（再选一次）；**`按需确认` 与 `云电脑` 两档会改变执行授权与环境，非用户明确要求不要动**
- **对话可用性**：✅
- **实测归属**：元宝/智谱/豆包均已实测；`按需确认`、`云电脑` 的切换后后果**未实测**

### 第 5 族 · 发送/语音族（会产生真实副作用）

- **按钮原文**：无文字
- **图标特征**：圆形上箭头 / 麦克风 / 声波圆点
- **位置参照**：**输入框右下角，最右两颗**
- **点击后果**：**真的发送一条消息**（消耗额度、写进会话历史）或开始录音
- **结果锚文本**：主区出现用户气泡 + 生成中状态
- **如何确认点对**：发送后输入框被清空
- **易混按钮**：`+`（同在一行两端，形状都是圆）
- **误点后果与恢复**：已发送无法撤回（部分软件可"编辑/删除"）；**不要在有内容的输入框里试探这两颗**
- **对话可用性**：✅（这就是对话本身）
- **实测归属**：**三家均未实测（刻意未点）**

### 第 6 族 · 消息工具条族（悬停才出现，易误判"按钮不存在"）

- **按钮原文**：`复制` / `收藏` / `👍` / `👎` / `↻`（重新生成）/ `🔊`（朗读）/ `↗`（分享）/ `…`（更多）
- **位置参照**：**鼠标悬停在某条回答气泡上时，气泡底部浮出的一排小图标**
- **点击后果（已实测）**：
  - 元宝 `↗` → **进多选分享视图**（`分享到微信` / `复制链接` / `生成图片` / `转为文档`），**不是复制**
  - 元宝 `…` → 只弹单项 `意见反馈`
- **如何确认点对**：图标排出现于气泡底部；指针一移开就消失——**点完立刻截帧**
- **易混按钮**：`↗`（分享）与 `复制`（在最左）
- **误点后果与恢复**：分享视图右下 `×` 退出
- **对话可用性**：✅
- **实测归属**：元宝 `↗`、`…` 实测；其余 6 颗**三家均未实测**

## 二、到新软件上的安全操作顺序（可直接执行）

- **本篇适用**：用户问到一个没用过的软件该按什么顺序点才不踩坑

1. **先列目录**：截图 → 把"左侧栏 + 输入行 + 右上角"三处的主要文字按钮全部记下来，**先不点**。
2. **先分类**：按上面六族给每颗按钮归族；**归不进任何族的，一律当第 2 族（危险）对待**。
3. **只点安全族**：第 1 族（会话入口）、第 3 族（`+`）、第 4 族（模式切换），并**逐颗截帧留证**。
4. **每点一颗前**：重读窗口矩形 + 当前帧，按"与锚文字同一行"的方式算落点；**点完立即截帧核对锚文本**。
5. **连续两次点空就换兜底**：不要连点第三次（见 `experience.md` E-009）。
6. **危险族**（第 2 族、第 5 族、第 6 族的生成/分享）**只在用户在场或已明确授权时**再点。
7. **记下软件级坑**：Esc 是否关菜单、窗口标题是否随会话变、`+` 菜单有几项——这三条几乎每个软件都要单独验。

## 三、判错兜底（"我到底进了哪一页"）

- **本篇适用**：用户问点完不确定自己进了哪一页、该怎么判断

| 你看到的锚文本 | 说明你在哪 | 该怎么做 |
|---|---|---|
| 输入框 + 工具栏（`+`/模式/`更多`） | 会话页 | 正常，可对话 |
| 主区大标题是"开始创作/描述你想生成的图片/风格标签" | 生图页 | 不在对话里，点会话入口族回去 |
| `Skills` / `技能广场` / 一墙卡片带「使用」 | 技能页 | 点某卡「使用」回聊天页并预填；或点会话入口 |
| 输入框占位是"处理复杂工作/今天有什么工作任务" | 任务台 | 可对话，但形式是"任务" |
| 主区一片纯黑、无标题但有输入区 | 新会话未渲染完 | **判 empty_chat**，不要判 unknown/loading（元宝实测） |
| 出现模态框（`创建项目`/命名框） | 被二级菜单带进了模态 | 点模态 ×，**不要按 Esc** |

## 补·兜底表增补：登录/扫码层（2026-11-06 评审 5.3 引入）

- **本篇适用**：用户问登录层、扫码层、跳过入口这类遮罩挡住界面时怎么办

| 你看到的锚文本 | 说明你在哪 | 该怎么做 |
|---|---|---|
| 二维码 / `扫码登录` / `点击登录` / 登录层里找不到 `跳过`、`以后再说` | 卡在登录层 | **报人工**，不重试、**不点 `×`**——剪映实测"点 × 直接退出整个进程"（E-023），不可恢复 |
| 登录层 BUT 有 `跳过`/`游客` | 可绕过 | 先确认绕过不会降级功能，再继续 |
| 弹 `…账号授权` + 权限清单 + 协议勾选框 | 授权页，不是文件选择页 | 不替用户勾协议、不点同意；点 `×` 退出即可（元宝 `腾讯文档`，E-024） |
| 点了同意像"没反应" | 前面大概率有未勾的协议行 | 先找协议勾选框，不要连点（同上） |

> **判据来源**：登录层属于"能力边界"而不是"没测完"。凡中间必须插入人工动作（扫码/短信/密码）且没有旁路的软件，统一按 `不可自动化 → 报人工` 处理，不要每轮重复无效尝试。
