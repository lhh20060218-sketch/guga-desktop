# examples：接力链推导示范（few-shot）

> 本文件只示范**怎么用第一层能力表 + 第二层规则推链条**，不是操作手册。
> 每条只写四段：目标 → 链条及为什么 → 接力点（文本 / 文件）→ 一个反问点。
> 不写步骤表、不写触发关键词、不写验收标准。

---

## 1. PDF 财报 → 3 分钟解说视频

**目标**：PDF 年报做 3 分钟解说视频。
**链**：读 PDF 出要点 → 改写成带时长口播脚本 → 喂视频生成出 mp4；隔两格两步。
**接力点**：前两步复制文本，脚本落文件喂视频端。
**反问**：专业商务还是白话？

## 2. 课堂录音 → 复习卡片

**目标**：课堂录音整理成复习卡片。
**链**：录音转写成文本 → 拆成问答卡片对 → 落成文件；音频→文本→结构化两格。
**接力点**：录音落文件喂转写，卡片化复制文本。
**反问**：纸质两栏还是电子卡片？

## 3. 会议记录 → 带配图周报

**目标**：会议记录做带配图周报。
**链**：纪要压成周报骨架 → 按骨架出配图提示词喂图片生成 → 组装回文档。
**接力点**：骨架复制文本喂图片端，图片落文件嵌回周报。
**反问**：发公司群还是给客户？

## 4. 开源 README → 教学短视频

**目标**：开源 README 做 2 分钟教学短视频。
**链**：README 抽成「安装/用法/避坑」大纲 → 扩成口播稿 → 喂视频生成出 mp4。
**接力点**：大纲复制文本扩稿，稿落文件喂视频端。
**反问**：新手还是已装依赖？

## 5. 短篇故事 → AI 漫剧短片

**目标**：短篇故事做 AI 漫剧短片。
**链**：故事拆成「镜号-画面-台词」分镜表 → 逐格出关键帧图 → 图生视频串起来。
**接力点**：分镜表落文件喂绘图端，关键帧落文件喂视频端。
**反问**：日漫还是美漫画风？
