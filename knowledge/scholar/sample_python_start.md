> 摘要：零基础学 Python 第一个月的路径与常见环境报错的判断处理
> 本篇回答：
>   1. "我想学编程，从哪开始？"
>   2. "装 Python 环境总报错怎么办？"

（示例文档：用于验证检索链路，正式知识库以队友B交付为准）

## 第一步：装环境（新手最常卡住的一步）

1. 到 python.org 下载最新稳定版，安装时**必须勾选 "Add Python to PATH"**——90% 的"python 不是内部或外部命令"都是这一步漏了
2. 判断标准：装完打开命令行输入 `python --version`，能看到版本号就是成功；报"不是内部或外部命令"就是 PATH 没加上，重装并勾选即可
3. 编辑器二选一：VS Code（装 Python 扩展）或 PyCharm Community。第一个月不要折腾 Jupyter 和虚拟环境

## 第二步：第一个月学什么

- 第 1 周：变量、if 判断、循环——每天写 10 行以上，不要只看视频
- 第 2 周：列表、字典、函数；做一个"命令行记账本"
- 第 3 周：文件读写、异常捕获（try/except），给记账本加存盘功能
- 第 4 周：综合小项目 + 复盘。判断标准：能不看教程独立写出 50 行的程序

## 第一个月不要做的事

不要碰：爬虫框架、机器学习、多线程、GUI。这些是第二个月以后的事，第一月碰它们只会卡死在环境配置上。
