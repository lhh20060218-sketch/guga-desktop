# 验收标准模板：什么算"活干好了"

咕嘎拿到交付物后，按下表逐条对照，全部命中才算合格；任何一条不命中，直接按"打回话术与理由模板.md"打回。标准写成可判句子，避免"质量好""表达清晰"这种没法点头的词。

| 任务类型 | 合格标准（全部命中才算过） |
|---|---|
| 周报（豆包/Kimi 写） | ① 含"本周完成事项 + 关键数据 + 下周计划"三段，三段都不空；② 每条事项一句话说清结果，关键数字（XX 万、XX%、XX 单）在少爷给的原始资料里能找到出处；③ 全文 ≤800 字，无错别字，专有名词与人名拼写与原件一致；④ 下周计划至少 3 条、每条带预计完成时间。 |
| PPT（WPS AI / Gamma / 豆包出大纲） | ① 页数与少爷要求 ±2 页，每页标题与大纲对得上；② 每页正文 ≤6 行字、字号统一、无占位符残留（"Lorem""点击输入标题"等）；③ 配图与该页论点相关，无明显水印/截图带浏览器边框；④ 导出 .pptx 后在 WPS 里能正常打开、不缺字体。 |
| 查资料对比（豆包/Kimi/秘塔 AI 搜索） | ① 冻结的对比维度全部覆盖，缺项明确写"未公开"而不是空着或编；② 每个关键数据（价格、坐席数、发布时间）附来源链接，且链接可点开、内容对得上；③ 同维度口径一致（都用"每坐席每月"或都用"年费"，不混）；④ 结论段"推荐哪款 + 理由"能在对比表里逐格找到依据。 |
| 写邮件（豆包/Copilot） | ① 称呼、落款、主题行齐全，收件人称谓与少爷平时习惯一致；② 正文 ≤300 字（除非少爷要求长文），一段话一个意思，无"兹有""望周知"这类公文腔；③ 关键时间、金额、人名核对无误；④ 语气是少爷平时那种语气，不是 AI 味的"尊敬的客户您好"。 |
| 整理文件归档（豆包出方案 + 咕嘎执行） | ① 目录树层级 ≤3 层，每个文件夹用途一句话能说清；② 每个文件都落到唯一位置，不重复、不遗漏；③ 文件命名统一格式（如"日期_项目_版本"），无"新建文件夹(2)""最终版_final_真的最终.docx"；④ 归档清单单独出一份，少爷可对着清单抽查 3 个文件找得到。 |
| 做表格（WPS AI / 豆包写公式） | ① 表头与少爷需求逐项对应，缺列直接问少爷而不是自己加；② 公式抽 3 个格子手算一遍对得上，#DIV/0!、#N/A 全部处理成空或 0；③ 数字单元格用数值格式不是文本格式，求和/透视能直接算；④ 导出 .xlsx 在 WPS 里打开不错位。 |
| 润色文章（豆包/Kimi） | ① 字数与原稿偏差 ≤10%，不擅自扩写或删段落；② 少爷原稿的关键数据、专有名词、人名一个不动；③ 通读一遍无病句、无"赋能/抓手/闭环"这类少爷讨厌的词；④ 润色点用批注或修订模式列出，少爷能看出改了哪几处。 |
| 翻译（豆包/通义千问对照） | ① 专业术语前后统一（同一个英文词全文译法一致）；② 数字、日期、货币单位换算正确，不保留英文原文夹生；③ 段落顺序与原文一一对应，不擅自合并/拆分；④ 篇幅按中文习惯压缩（英译中一般压到原文 70% 左右），不出现逐字硬译的长句。 |
| 生成图片（即梦/可灵/豆包绘图） | ① 一次出 ≥4 张候选、构图或风格有差异，不是同一张改色；② 主体清晰、无多指/缺手指/文字乱码（若图里要带字，必须字是对的）；③ 风格与少爷要的方向一致（商务/卡通/实拍感），不跑偏；④ 选定后局部改图 ≤3 轮能改到位，超过 3 轮换即梦重抽。 |
| 会议纪要（豆包/Kimi 吃转写稿） | ① 含"会议时间/参会人/决议事项/待办（谁+什么时候交）"四块；② 待办每条都有责任人和截止时间，没说的标"待确认"，不替人拍脑袋派活；③ 口语转书面，去掉"嗯""那个"这类语气词，但保留关键人名原话；④ 转写稿里有分歧的地方，纪要两边观点都记，不偏向任一方。 |

判定动作：咕嘎拿到交付物先逐条打勾，能勾满 → 呈少爷过目；勾不满 → 直接打回，不攒着、不替执行方圆场。
