# cursor-export：复制回答代码块 / 接受改动 / 落文件

- **剧本ID**：cursor-export
- **软件**：Cursor 桌面客户端（Windows，版本 3.27.12）
- **动作目标**：把模型给的代码要么复制走自己贴，要么经 Agent 模式 Accept 落到项目文件里。

## 前置条件

1. Chat 面板里已有含代码块的回答（Ask 模式代码块带 Copy；Agent 模式改动以 diff 出现，带 Accept/Reject）。
2. 若走 Accept 落文件路径：当前会话处于 Agent 模式（面板顶部切换，默认 Agent），模型已改完文件，编辑器出现 diff 预览。
3. 目标文件未被锁只读；Git 工作区干净或已知实验分支。

## 步骤序列

1. **定位代码块**：在 Chat 面板历史区找到目标回答并滚到代码块。**等待判据**：代码块右上角/右下角可见操作按钮区（官方 apply 文档：代码块右上角有 'Accept'/'Reject' 按钮）。
2. **路径 A —— 只复制不改文件（Ask/Chat 模式）**：
   - **元素特征**：代码块上的 "Copy" 按钮（论坛 2026-06 确认：Ask/Chat 模式代码块仅保留 Copy，Apply 已被官方移除）。**动作**：单击 "Copy"。**等待判据**：按钮短暂变成 "Copied"（**待真机核对**反馈文案），剪贴板已含该代码块全文。
   - **落文件动作**：切回编辑器打开目标 .py/.ts 文件，光标定位插入点，`Ctrl+V` 粘贴并 `Ctrl+S` 保存。**等待判据**：标题栏未保存圆点消失。
3. **路径 B —— 接受 Agent 模式 diff（直接落文件）**：
   - **元素特征**：Chat 代码块右上角的 "Accept" 按钮（官方原文）；批量接受 `Ctrl+Enter`（官方：Accept all changes）。**动作**：先在编辑器 diff 预览里逐块扫一眼，确认无误后单击 "Accept"，或 `Ctrl+Enter` 接受全部。**等待判据**：编辑器红绿 diff 高亮消失，文件变成新版本，代码块上的 "Accept"/"Reject" 按钮消失。
   - **反悔**：官方 `Ctrl+Shift+Backspace` = Reject all；或编辑器 `Ctrl+Z` 回退。**等待判据**：diff 还原，文件回到改动前。
4. **核验落盘**：`Ctrl+S` 强制保存一次，确认文件树目标文件 mtime 已更新、无未存圆点。

## 成功判据

路径 A——剪贴板粘贴代码与 Chat 里代码块逐字一致；路径 B——文件内容已是模型建议版本，`git diff` 可见改动行。

## 异常处理

- **点 Copy 后粘贴是空的**：少爷，多半是剪贴板被别的程序（截图工具、密码管理器）抢走。重新点一次 Copy 立刻切到编辑器 `Ctrl+V`。
- **点 Accept 后 diff 闪一下又弹红叉**：常见是目标文件被别的进程占用或路径里有符号链接。关掉其他编辑器实例，确认文件非只读再点一次 Accept；不行退回路径 A 手动复制粘贴。
- **Accept 完发现改错了文件**：`Ctrl+Z` 连续回退；已保存则 `Ctrl+Shift+P` → "Git: Discard Changes"（仅当愿放弃未提交改动）。
- **Agent 模式改了一堆文件只想要其中一个**：diff 预览里每个文件块有独立 Accept/Reject，逐块 Reject 掉不要的，别 Accept all。
- **Ask 模式代码块找不到 Apply**：少爷，2026 年官方已移除 Ask/Chat 模式的 Apply，只留 Copy；要自动落文件就切到 Agent 模式（面板顶部切换）。
