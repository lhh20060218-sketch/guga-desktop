# cursor-ask：在 Cursor Chat 面板提问并拿到回答

- **剧本ID**：cursor-ask
- **软件**：Cursor 桌面客户端（Windows，版本 3.27.12）
- **动作目标**：在右侧 Chat 面板输入一个问题，等待模型返回文字回答或代码建议。

## 前置条件

1. Cursor 客户端已启动，且已打开一个本地项目文件夹（菜单栏 File → Open Folder），不是空白欢迎页。
2. 已登录 Cursor 账号（左下角头像已出现，非"Sign in to get started"提示）。
3. 当前网络可访问 api.cursor.com；若未登录，提问时会弹登录墙，本剧本走不通。
4. 编辑器处于焦点状态，没有别的模态弹窗挡着。

## 步骤序列

1. **元素特征**：快捷键 `Ctrl+L`（官方快捷键表：Toggle Sidepanel，绑定到 Chat 模式时即打开右侧 Chat 面板）。**动作**：在编辑器任意处按 `Ctrl+L`。**等待判据**：屏幕右侧滑出 Chat 面板，顶部出现 "Agent / Ask / IDE" 模式切换栏（待真机核对确切标签文字），面板底部出现可输入的多行文本框。
2. **元素特征**：Chat 面板底部输入框（占位符原文官方文档未给出，常见为 "Ask anything about your codebase…" 之类，**待真机核对**）。**动作**：单击输入框使其获得焦点，键入问题，例如"解释一下这个项目里 main.py 的启动流程"。**等待判据**：输入框内出现你刚敲的文字，且输入框右下角出现发送按钮（箭头图标，**待真机核对**）。
3. **元素特征**：发送动作——快捷键 `Enter`（官方：Queue message，默认即发送）；若已输入多行想用 Ctrl+Enter 强制发送，官方亦有 `Ctrl+Enter when typing`。**动作**：按 `Enter`。**等待判据**：你这条提问以用户气泡形式出现在 Chat 面板历史区，紧接着下方出现模型回复占位（流式输出光标 / "Thinking…" 之类，**待真机核对**）。
4. **元素特征**：模型回复流。**动作**：不干预，静等。**等待判据**：回复文字停止滚动，末尾不再出现打字光标；若回复含代码，代码块右下角出现 "Copy" 按钮（论坛确认 Ask/Chat 模式下代码块现仅保留 Copy，不再有 Apply）。

## 成功判据

Chat 面板历史区里同时存在"你刚才的提问"和"一段完整、无截断标记的模型回答"，且回答末尾没有报错红条。

## 异常处理

- **未登录**：少爷，按 Ctrl+L 后输入框灰着或点发送弹登录窗，别硬点。去左下角头像 → Sign in，走浏览器 OAuth 回跳，登录成功后重跑本剧本。
- **加载超过 30 秒仍无流式输出**：网络到模型那段堵了。按 `Ctrl+Shift+Backspace`（官方：Cancel generation）掐掉，再按一次 Enter 重发；连续 3 次都卡，检查代理/VPN 或换模型（`Ctrl+/` 循环切模型）。
- **回答中途断流（出现 "Generation stopped" 或半截代码）**：少爷，这是服务端截断。直接在输入框补一句"继续说完上一条"，走追问剧本即可，不用重问。
- **回答里出现红色报错条（401/429/quota）**：401 是登录掉了，重登；429 是额度用完，去 cursor.com 看用量池，或等限流窗口。
- **输入框敲不进字**：焦点其实在编辑器而不是 Chat。点一下输入框内部再敲，或按 `Ctrl+L` 先把面板关掉再开一次。
