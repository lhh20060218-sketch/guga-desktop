# claude-ask：Claude（网页版）提问取回答

- **剧本ID**：claude-ask
- **软件**：Claude 网页版（https://claude.ai/，本机未装桌面端，以浏览器为准）
- **动作目标**：打开 claude.ai、登录、新会话发出第一条问题并拿到完整回答

## 前置条件
1. 浏览器打开 https://claude.ai/ ；Claude 本机未装，全程网页操作。
2. 账号已注册，登录为官方两种之一：「Continue with Google」授权弹窗，或「Continue with email」收邮件里的登录链接（magic link）。
3. 网络通畅且在官方支持地区；登录动作请少爷本人完成，咕嘎不代读口令。

## 步骤序列
1. **元素特征**：地址栏 `https://claude.ai/`；未登录时出现登录页，含「Continue with email」输入框与「Continue with Google」按钮（官方原文）。
   **动作**：少爷本人选 Google 授权或点邮件里的登录链接。
   **等待判据**：跳入主界面，左侧出现历史列表，底部出现可输入对话框。
2. **元素特征**：左下角「+」按钮（官方原文：lower left 的 "+" button）。
   **动作**：点「+」开空白新会话，不接旧对话。
   **等待判据**：对话区清空，当前模型名显示在输入框下方（web 端官方位置）。
3. **元素特征（可选）**：输入框下方模型名（Opus / Sonnet / Haiku）。
   **动作**：深度推理用 Opus、日常用 Sonnet、要快选 Haiku；默认亦可。点模型名 → 下拉选 →「More models」看更多。
   **等待判据**：下方模型名变为所选。
4. **元素特征**：底部输入框（占位符官方未给中文原文，待真机核对）。
   **动作**：单击并键入问题全文。
   **等待判据**：文字上屏，右侧提交按钮由灰转亮。
5. **元素特征**：提交按钮（官方原文 submit button，图标为发送箭头，待真机核对）或回车。
   **动作**：点击提交（或 Enter）。
   **等待判据**：提问成为上方用户气泡，下方回答区开始流式输出，出现中断按钮（原文待真机核对）。
6. **元素特征**：回答区 Markdown 正文。
   **动作**：静坐等输出跑完，不切会话、不刷新。
   **等待判据**：文字停滚、中断按钮消失、底部操作图标行重现。

## 成功判据
回答完整无截断，底部图标行点亮，页面无「something went wrong」红字或超限提示。

## 异常处理
- **卡在登录页**：少爷，claude.ai 要您本人登录，咕嘎不碰口令；进来后从步骤 2 重走。
- **60 秒无首字**：少爷，多半在排队。咕嘎点中断按钮，半分钟后原样重发；仍卡就把 Opus 降到 Sonnet。
- **答到一半断流**：少爷，咕嘎补一句「请接着上面继续」让它续写，还断就换问法。
- **弹用量超限**：少爷，本轮额度到了（免费版约每 5 小时重置），等重置或降 Haiku 省着用。
- **地区不支持打不开**：少爷，当前网络进不去 claude.ai，换好网络再说。
