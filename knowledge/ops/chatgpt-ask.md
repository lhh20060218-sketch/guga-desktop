# 剧本ID：ops-chatgpt-ask-001

## 软件
ChatGPT（本机未安装桌面客户端，本剧本以网页版 chatgpt.com 为准；如需 Windows 桌面应用，入口与按钮待真机核对）

## 动作目标
从打开浏览器到在全新会话里发出一次提问，并拿到 ChatGPT 一段完整、不再变化的回答。

## 前置条件
- 少爷已能正常上网，浏览器为 Edge 或 Chrome（任一现代浏览器均可）。
- 知道要问的问题或要下的指令原文。
- 官方说明：ChatGPT 网页版可在未登录状态下先试用；只有登录或注册账号后，对话才会被保存下来。登录方式官方列出 Google、Microsoft、Apple 以及邮箱加密码四种，按页面所选走对应授权即可。

## 步骤序列

1. **元素特征+动作+等待判据**
   - 元素特征：浏览器地址栏。
   - 动作：在地址栏输入 chatgpt.com 并回车。
   - 等待判据：页面标题出现 ChatGPT，中央出现可输入的文本框（官方称 message box / prompt 文本框）。

2. **元素特征+动作+等待判据**
   - 元素特征：若跳转到登录/介绍页，出现「Log in / Sign up」入口及 Google、Microsoft、Apple、邮箱登录按钮。
   - 动作：未登录试用可直接寻找「继续使用 / 先体验」入口进入；如需保存对话，选对应账号登录。
   - 等待判据：回到中央大文本框、左侧出现「New chat（新对话）」按钮，页面可直接输入。

3. **元素特征+动作+等待判据**
   - 元素特征：页面中部的大文本输入框，占位提示大致为输入 prompt（具体占位文案待真机核对）。
   - 动作：单击输入框，键入少爷的问题或指令。
   - 等待判据：文字完整显示在框内，右侧出现可点的发送按钮。

4. **元素特征+动作+等待判据**
   - 元素特征：输入框右侧的圆形发送按钮（图标为向上箭头；确切样式待真机核对）。
   - 动作：点击发送，或按回车键（Shift+回车换行）。
   - 等待判据：用户提问出现在右侧对话流，下方开始流式输出回答文字。

5. **元素特征+动作+等待判据**
   - 元素特征：回答正文区域。
   - 动作：不做操作，静候输出。
   - 等待判据：回答下方出现「停止生成」转为普通操作按钮（重试/复制等），且文字停止滚动、不再逐字增加，即视为回答完成。

## 成功判据
对话流里同时出现少爷的提问与一段不再变化的 ChatGPT 回答，内容对题；如需留存，左侧会话列表已生成该条对话。

## 异常处理
- 少爷若点了没反应：多半是网络或地区访问受限，先让管家确认能否打开 chatgpt.com，再重试。
- 若提示登录墙弹得太凶：管家建议少爷先用未登录试用拿到回答，需要存档再登录。
- 回答中途卡住或截断：管家会在该回答下方点「重试/Regenerate」让它重写一遍，不另起新对话。
