# wenxin-export：文心一言复制或分享回答结果

- **剧本ID**：wenxin-export
- **软件**：文心一言（桌面客户端 `C:\Program Files\wenxin\文心.exe` 3.3.6；网页版 https://wenxin.baidu.com ）
- **动作目标**：把某一轮 AI 回答拿出来——优先用官方"复制全文"复制到剪贴板，再粘贴到 Word / 记事本 / 飞书等；需对外分享则走官方"分享"生成链接。

## 前置条件

1. 已拿到至少一条完整 AI 回答气泡，且流式输出完毕（气泡下方操作图标行已出现）。
2. 目标应用已打开（Word / 记事本 / 飞书 / 微信对话框等），光标停在粘贴位置；分享场景浏览器或聊天窗口就绪。
3. 账号已登录；未登录"分享"可能受限。
4. 已确认要导出的就是那一轮回答——复制按钮挂在**每条**回答气泡下方，点错就复制错。

## 步骤序列

1. **定位目标回答气泡**
   - 元素特征：聊天区左侧（AI 侧）某条回答气泡，底部一行小图标（复制/分享/重新生成/点赞等，顺序待真机核对）。
   - 动作：滚动到目标气泡，鼠标悬停到底部图标行。
   - 等待判据：图标行完整露出，能看到复制和分享图标。

2. **点击"复制全文"**
   - 元素特征：气泡底部操作行中的复制图标按钮（形似两个重叠方块，tooltip"复制"或"复制全文"待真机核对）。
   - 动作：点击。官方资料还提供"复制为Markdown格式"（单按钮还是下拉待真机核对）；纯文字粘 Word 用普通复制，粘支持 Markdown 的工具用 Markdown 格式。
   - 等待判据：按钮出现视觉反馈（图标变勾或弹"已复制"toast，文案待真机核对）。

3. **切到目标应用粘贴**
   - 元素特征：目标应用窗口编辑区。
   - 动作：Alt+Tab 切过去，光标定位后按 Ctrl+V。
   - 等待判据：回答全文出现在光标位置；段落、列表保留（Markdown 格式粘到记事本会露出 `#`、`**`，属正常）。

4. **（可选）走官方"分享"生成公开链接**
   - 元素特征：同一操作行中的分享图标（形似向外箭头/链接符号，tooltip"分享"待真机核对）。
   - 动作：点分享按钮，在弹出面板勾选要公开的 AI 回答（官方资料：可同时勾选多条），点"分享"生成公开 URL。
   - 等待判据：拿到一条 `wenxin.baidu.com` 开头的链接。**注意**：该链接公开可访问，删对话后仍可能有效（媒体实测），含隐私内容别直接分享。

## 成功判据

目标应用里出现本轮回答完整文字，无缺段、无乱码、无气泡 UI 残留；走分享的话，能粘贴出一条 `wenxin.baidu.com` 开头的公开链接。

## 异常处理（管家口吻）

- **点复制后粘贴出空的或旧内容**：复制后又复制了别的东西。回文心重新点复制，看到"已复制"立刻切过去 Ctrl+V，中间别再复制。
- **复制夹带"由文心大模型 X.X 生成"署名**：那是你手动拖选了整个气泡。用官方复制按钮，别拖选；署名一般不会被官方复制带走。
- **想导出 .docx / .pdf 但找不到"导出"按钮**：官方资料里文心**没有**一键导出入口，只有"复制"和"分享"。正确做法：复制全文 → 切到 Word 粘贴 → 另存为 .docx；或 Ctrl+P 把分享页另存为 PDF。
- **分享按钮没反应 / 对方打不开链接**：未登录受限先登录；链接打不开可能是你删了对话，重新生成一条；新链接也不行就是服务侧问题，过几分钟再试。
- **粘到 Word 格式全乱 / 表格对不齐**：改走"复制为Markdown格式"粘到支持 Markdown 的编辑器再另存；表格对不齐就让 AI 输出"请用 CSV 格式输出上表"，再粘到 Excel。
