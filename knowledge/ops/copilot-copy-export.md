# copilot-copy-export：Copilot 复制/导出回答结果

- **剧本ID**：copilot-copy-export
- **软件**：Microsoft Copilot（Windows 桌面客户端，copilotapp.exe，版本 156.0.4314.58）
- **动作目标**：把 Copilot 生成的回答文本复制到剪贴板，再粘贴到目标应用（Word/记事本/飞书文档）；客户端无官方导出功能时，以复制粘贴为交付路径

## 前置条件

1. 已完成 copilot-ask/copilot-followup，对话区中有已生成完毕的回答。
2. 回答下方操作工具栏已出现（含复制图标，具体文字待真机核对）。
3. 目标应用（记事本/Word/飞书等）已打开并备好粘贴位置。
4. 已确认 Copilot 桌面客户端当前版本（156.0.4314.58）**无官方一键导出 PDF/Word 功能**——检索微软支持站与公开报道未发现「导出对话」菜单；365 Copilot（企业版）的导出能力与本客户端不是同一产品。本剧本以「复制+粘贴」为交付路径。

## 步骤序列

1. **元素特征**：目标回答气泡下方的操作工具栏，含复制图标（文档形状图标，按钮文字「复制/Copy」待真机核对）。**动作**：鼠标悬停到该回答上，工具栏出现后点复制图标。**等待判据**：按钮短暂变为「已复制/Copied」状态（文字待真机核对），或弹剪贴板提示，文本已进剪贴板。
2. **元素特征**：若复制按钮不生效，备选：鼠标从回答开头拖到结尾选中整段。**动作**：右键 → 选「复制」（或按 Ctrl+C）。**等待判据**：选中文本变高亮，剪贴板已更新。
3. **元素特征**：目标应用编辑区。**动作**：点击目标应用使其前台，光标处按 Ctrl+V 粘贴。**等待判据**：Copilot 回答文本出现在目标文档中，排版基本保留（换行、列表）。
4. **元素特征**：粘贴后内容。**动作**：肉眼核对完整性。**等待判据**：开头、结尾都在，中间无缺段；丢内容则回步骤 2 重新全选复制。

### 关于分享链接（如实说明）

- Copilot 网页版曾提供「分享/Share」按钮生成链接；**桌面客户端 156.0.4314.58 是否保留分享按钮、按钮原文为何，微软官方帮助中心未检索到可靠文案，标「待真机核对」**。若少爷在回答下方看到分享图标，点击后浏览器打开带链接页面，复制地址栏 URL；没有就走复制粘贴路径。

## 成功判据

- 目标应用中出现完整的 Copilot 回答文本，无截断、无乱码；或文本已存于剪贴板（任意输入框 Ctrl+V 验证）。

## 异常处理

- **复制按钮点了没反应**：少爷，改用鼠标拖选整段回答 + Ctrl+C，这是最稳的兜底；Copilot 偶发复制按钮无响应。
- **粘贴后格式全丢**：少爷，Word 里粘贴选「保留源格式」；纯文本粘贴丢换行就回 Copilot 重新拖选，从回答上端多拉一行再 Ctrl+C。
- **粘贴后只贴到一半**：少爷，回答太长时拖选易漏尾部；回 Copilot 把回答区滚到底逐段补选，或直接对回答说「把上面这段导出成纯文本给我」。
- **找不到分享链接入口**：少爷，桌面客户端不一定有分享按钮，别硬找；需要分享就直接复制文本贴到目标应用，或改用网页版。
- **剪贴板被占用**：少爷，Ctrl+V 贴出的不是 Copilot 内容说明剪贴板被覆盖；回 Copilot 再点一次复制，立刻切到目标应用粘贴。
- **回答里含代码块/表格**：少爷，代码块右上角通常有「复制代码」按钮（待真机核对），优先用它；表格在纯文本粘贴时塌成一行，需保留就先贴 Word。
