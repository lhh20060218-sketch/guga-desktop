# doubao-copy：豆包桌面客户端 · 复制回答文本 / 生成分享链接

- **剧本ID**：doubao-copy
- **软件**：豆包桌面客户端（Windows，v2.25.16）
- **动作目标**：把豆包回答拿到手——复制成纯文本粘到目标应用，或生成对话分享链接

> 说明：官方帮助中心未见豆包客户端有"导出 Word/PDF"按钮，导出只走复制全文→粘贴、复制对话分享链接两条路。

## 前置条件

1. 已有一条完整回答气泡，底部工具栏完整出现（同 doubao-ask 成功判据）。
2. 已想好粘贴目标或链接接收人；剪贴板未被截图工具占用；已登录、网络正常。

## 步骤序列

### 路径 A：复制单条回答全文

1. **元素特征**：回答气泡底部工具栏的"复制"图标（官方原文："在回复底部的工具栏中复制或朗读全文"，https://www.doubao.com/work/docs/zh-cn/articles/628589138051-chats ；是否带"复制"字样 **待真机核对**）。
   **动作**：鼠标悬停回答气泡让工具栏浮现，单击"复制"。
   **等待判据**：出现"已复制"toast（文案 **待真机核对**）；剪贴板已为该回答纯文本。

2. **元素特征**：目标应用输入区。
   **动作**：切到目标应用，Ctrl+V 粘贴。
   **等待判据**：粘出文字与豆包回答一致；表格 / 代码块可能丢格式。
   （只要某一段：改鼠标拖选该段文字，松开后浮动工具栏点"复制"——官方四项为"复制、朗读、追问、注释"——再 Ctrl+V。）

### 路径 B：复制整条对话分享链接

1. **元素特征**：左侧"最近"列表里当前对话条目。
   **动作**：鼠标悬停，单击条目右侧浮出的菜单图标。
   **等待判据**：弹出右键菜单，官方原文菜单含"复制分享链接"（完整菜单见同 URL 截图）。
2. **元素特征**：菜单中"复制分享链接"（官方原文，副标题"复制该对话的链接以便将对话内容分享给其他协作者"）。
   **动作**：单击。
   **等待判据**：剪贴板为 https://www.doubao.com/... 链接。
3. **动作**：Ctrl+V 粘到飞书 / 微信 / 邮件发出。
   **等待判据**：对方点开可见整条对话只读视图（可见范围 **待真机核对**；敏感内容先提醒少爷）。

## 成功判据

- 路径 A：目标应用 Ctrl+V 出的文字与回答气泡逐字一致（允许换行差异）。
- 路径 B：剪贴板为 doubao.com 域名的 https 链接，浏览器打开能看到本对话。

## 异常处理

- **点"复制"无反应**：关掉挡路浮层再点；仍不行改用拖选 + Ctrl+C。
- **粘贴后格式乱 / 代码块缩进丢**：纯文本复制的预期行为，回报少爷是否需要重包代码块再复制。
- **粘出空内容**：剪贴板被抢了，回豆包重点"复制"，10 秒内立刻去粘。
- **菜单找不到"复制分享链接"**：本机主客户端 v2.25.16 与官方截图的"豆包工作"客户端可能不一致（菜单项 **待真机核对**）；没有就改用路径 A。
- **链接对方打不开**：可能内容审核未过或仅自己可见；不要反复重发，回报少爷改发正文。
- **浮层挡气泡**：先关浮层（Esc 或 ×）。
- **误点"删除"**：菜单最底红字是删除，鼠标绕开；误删先查"设置 > 已归档内容"。
