# doubao-ask：豆包桌面客户端 · 提问取回答

- **剧本ID**：doubao-ask
- **软件**：豆包桌面客户端（Windows，v2.25.16，D:\豆包\Doubao\app\Doubao.exe）
- **动作目标**：在豆包桌面客户端发起新对话，输入问题并拿到 AI 文字回答

## 前置条件

1. 豆包客户端已安装并已登录（手机号 / 抖音号 / Apple ID 任一）；未登录本剧本不处理。
2. 主窗口已打开并在前台；最小化则从任务栏或开始菜单"豆包"唤出。
3. 网络可达 www.doubao.com；无推广弹窗 / 设置面板遮挡输入区。

## 步骤序列

1. **元素特征**：主窗口底部输入框，网页版占位符原文"有什么我能帮你的吗？"（https://www.doubao.com/chat ；桌面端占位符 **待真机核对**）。
   **动作**：单击输入框获焦。
   **等待判据**：光标闪烁，右下角"发送"图标由灰变亮。

2. **元素特征**：输入框本体。
   **动作**：键盘输入少爷问题原文；单次不超过 2000 字。
   **等待判据**：框内文字与预期一致，"发送"图标亮起。

3. **元素特征**：输入框右侧"发送"图标（官方原文见 https://www.doubao.com/work/docs/zh-cn/articles/869365200695-task-quick-start ；桌面端形状 **待真机核对**）。
   **动作**：单击"发送"，或按 Enter（Enter 发送 / Shift+Enter 换行 **待真机核对**）。
   **等待判据**：用户提问气泡出现，下方豆包回答气泡开始流式输出。

4. **元素特征**：回答气泡。
   **动作**：等待输出完毕，不中途发新消息。
   **等待判据**：底部工具栏完整出现（官方列出：复制 / 朗读 / 点赞 / 点踩 / 开启新对话 / 转发 / 消耗额度 / 重新生成 / …，https://www.doubao.com/work/docs/zh-cn/articles/628589138051-chats ；桌面端顺序 **待真机核对**）。

## 成功判据

- 对话区同时有一条用户气泡和一条豆包回答气泡；
- 回答底部工具栏已完整渲染；
- 回答内容切题，不是"我没听懂"类兜底话术。

## 异常处理

- **未登录就发送**：跳到登录页。管家停手回报少爷本人扫码 / 收短信，登录后重发。
- **发送无反应**：先确认输入框获焦再按 Enter；等 15 秒仍卡，按 Ctrl+K（**待真机核对**）开新对话重试。
- **加载超 30 秒无输出**：点回答下方"重新生成"重试一次；仍卡，回报少爷是否换问题。
- **回答中途断流**：原地点"重新生成"，不要重发原问题（避免上下文重复）。
- **弹广告 / 会员推广浮层**：点右上角×关闭，关不掉按 Esc；绝不在浮层里点"立即开通"。
- **弹额度用完 / 登录过期**：立即停手，原样回报少爷。
- **窗口切后台**：先点任务栏豆包图标拉回前台再操作。
