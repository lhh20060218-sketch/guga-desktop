# wps-export：WPS AI 生成结果的插入 / 复制 / 另存

## 剧本ID / 软件 / 动作目标
- 剧本ID：wps-export
- 软件：WPS Office（WPS 文字 / 智能文档，客户端 Windows 版，本机 12.2.0.23196）
- 动作目标：把面板里已生成好的回答落到文档或带走，三选一：① 插入文档光标处；② 复制到剪贴板；③ 连同文档另存为本地文件。

## 前置条件
1. 已用 wps-ask / wps-followup 生成至少一轮回答，且生成结束、加载态消失。
2. 文档可编辑，光标已在希望插入的位置附近就位。
3. 账号登录、联网正常；另存本地不耗 AI 额度，但需本机写入权限。

## 步骤序列（路线 A：插入到文档）
1. **元素特征**：AI 生成结果下方操作按钮组（官方未公开具体按钮文字）。
   **动作**：在结果卡片下方找"插入""插入到文档""采纳"之类按钮（确切文字与位置待真机核对）。
   **等待判据**：鼠标悬停按钮高亮；不确定就逐个悬停看提示文字。
2. **元素特征**：上述插入按钮。
   **动作**：点击。
   **等待判据**：整段文字写入文档光标位置，结果出现"已插入"类标记（具体提示待真机核对）。
3. **元素特征**：文档编辑区。
   **动作**：肉眼核对段落是否完整、有无重复乱码。
   **等待判据**：目标段落出现在对应位置，可继续编辑。

## 步骤序列（路线 B：复制走）
4. **元素特征**：AI 生成结果文字区。
   **动作**：鼠标拖选要带走的文字（或点结果卡片上"复制"按钮，文字待真机核对）。
   **等待判据**：文字被蓝底高亮选中。
5. **元素特征**：选中文字后的右键菜单/键盘。
   **动作**：按 Ctrl+C，或右键选"复制"。
   **等待判据**：剪贴板已存内容（切到记事本 Ctrl+V 能粘出即验证）。

## 步骤序列（路线 C：另存为本地文件）
6. **元素特征**：文档顶部"文件"菜单（或左上角"WPS 文字"入口）。
   **动作**：点"文件→另存为"（路径以实际为准，待真机核对）。
   **等待判据**：弹出另存为对话框。
7. **元素特征**：另存为对话框。
   **动作**：选保存位置、填文件名、类型选 .docx，点"保存"。
   **等待判据**：对话框关闭，标题栏文件名更新，目标路径出现该 .docx。

## 成功判据
- 路线 A：AI 成稿完整出现在光标处，可继续人工编辑。
- 路线 B：在文档外任意可粘贴处 Ctrl+V 能完整粘出回答。
- 路线 C：本地路径下存在刚另存的 .docx，双击打开内容与编辑区一致。

## 异常处理
- **结果下找不到"插入/复制"按钮**：少爷，各版本按钮不一，别硬找；最稳兜底是面板里拖选文字 + Ctrl+C，回文档 Ctrl+V，效果等同插入。
- **点插入没反应**：少爷，多半光标没在可编辑区；先在文档里点一下落好光标，再回去点插入。
- **插入后格式全乱/带面板样式**：少爷，粘进文档后用"只粘贴文本"（右键粘贴选项选无格式）或在"开始"选项卡刷成正文样式。
- **复制后粘出来是空的**：少爷，重新拖选确保蓝底覆盖整段再 Ctrl+C；个别面板需先点一下结果卡片使其激活才能复制。
- **另存为点不动/提示只读**：少爷，只读打开的文档先"另存为"到自己桌面再改；盘符满了换位置。
- **加载没完就去点插入**：少爷，先等加载态消失再操作，否则只插入半截。
- **网络掉线**：少爷，面板里已生成的文字不受影响，照常复制/插入；只是别再触发新生成。
