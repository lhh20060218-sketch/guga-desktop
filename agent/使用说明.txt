【这是什么】
  网页里的咕嘎是"管家的大脑"，这个包是咕嘎的"手和脚"——
  配对后，网页派"本机执行"的单会由咕嘎本体接单，
  真实拉起您电脑上的 AI 软件（豆包等）干活，
  产物回传网页，走同一套监工验收（不合格真打回）。

【三步开始】

  第 1 步：环境自检（推荐先做，30 秒）
    · 双击「1-环境自检.bat」，或在本目录打开命令行执行：
        python guga_selfcheck.py
    · 它会只读扫描本机已装的 AI 软件（豆包 / WorkBuddy /
      Cursor / VS Code / 微信 / Chrome / Edge），
      报告存为 guga_selfcheck_report.json。
    · 全程不联网、不写注册表、不启动任何程序、不驻留后台。

  第 2 步：与网页配对（核心功能，一次性，双击即用，免装 Python）
    · 网页右上点「🩺 自检」→ 底部点「🔗 生成配对码」，记住 6 位数字；
    · 双击「GUGA-Agent.exe」（免安装独立版，电脑上没有 Python 也能跑）；
      或双击「2-启动咕嘎本体.bat」走 Python 通道（会自动装依赖）；
    · 按提示输入 6 位配对码，显示"配对成功 + 开始值守"即可，
      这个黑窗口保持开着（这就是咕嘎的手和脚在值守）；
    · 回到网页：直接派单即可——大脑识别到"打开豆包"这类真机任务
      会自动派给本体；也可手动点「🖥 本机执行」强制真机执行。

  第 3 步（可选）：命令行方式（与双击等效）
      python guga_agent.py 123456     （换成您的 6 位配对码）

【真机指挥（手动模式，可选）】
    · 先打开豆包并登录，然后执行：
        python guga_executor.py "你的问题" "你的追问"
    · 咕嘎会自动开新对话提问、追问、取回答案，
      每一步截图存证到 evidence\ 文件夹。

【安全说明 —— 评委可放心】

  · 自检脚本纯只读：只探测常见安装路径是否存在；
  · 值守程序只响应网页任务，空闲时每 4 秒一次心跳，不做别的；
  · 执行器内置 FAILSAFE：鼠标甩到屏幕左上角立即紧急中止；
  · 执行前自动保存剪贴板，结束后恢复；开新对话，绝不污染
    您现有的会话；
  · 本体只指挥"本机软件的 AI"，不读取、不上传您软件里的
    任何隐私内容，产物仅包含任务答案本身；
  · 比赛结束后：关掉值守窗口、删除本文件夹即可，无任何残留。

【常见问题】

  Q1：双击 bat 提示找不到 Python？
      到 python.org 安装 Python 3.8+，安装时勾选
      "Add Python to PATH"，然后重新双击。

  Q2：双击了 .py 文件，弹出"正在下载 适用于 Linux 的 Windows 子系统"？
      您的电脑把 .py 文件关联给了 WSL（Linux 子系统），不是咕嘎的问题。
      关掉那个窗口，回到 guga-desktop 文件夹，认准双击
      「2-启动咕嘎本体.bat」即可；启动脚本会自动识别并绕开
      WSL / 应用商店的假 Python。若提示没有 Python，去
      python.org 装 Windows 版（勾选 Add Python to PATH）。

  Q3：启动脚本提示"Dependency install failed"（装依赖失败）？
      多是国内网络连不上 pypi 官方源。新版启动脚本已默认改走
      清华镜像并自动重试；若仍失败，按黑窗口里打出的真实报错处理：
        · 网络需要代理：先给 pip 配好代理再重试；
        · 提示 No module named pip：执行 python -m ensurepip --upgrade；
      处理完重新双击「2-启动咕嘎本体.bat」即可。

  Q4：杀毒软件提示风险？
      本包为开源 Python 脚本，可用记事本打开全部源码审查；
      自检脚本不做任何写入与联网操作。

  Q5：配对码提示无效或已过期？
      配对码 10 分钟有效。回网页点「🔗 重新生成」再试。

  Q6：派单后本机没动静？
      确认值守窗口还开着、豆包已登录；若窗口报"未在本机
      探测到豆包"，先安装并打开豆包一次。

  Q7：执行器中途停手了？
      按 KB 剧本安全机制：画面校验不过就停，不会乱点。
      值守程序会如实回报失败，网页咕嘎会自动重新派单。
